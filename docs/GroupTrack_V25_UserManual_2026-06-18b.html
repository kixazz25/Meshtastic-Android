1 · Getting Started

First-time setup, in order. Do these once before your first ride; trail and tile data then persist on the device.

This chapter walks first-time setup from a fresh install through optional radio pairing. Each step persists: once you've imported trails and downloaded map tiles, they stay on the device across app updates and restarts — you don't redo this before every ride.

Draft note (remove before publish): the procedures in this chapter are drafted from current app behavior and prior notes. Steps marked [verify] need a confirming pass on the device to lock exact button labels / order before this ships to testers.

1.1 · Installing the software

SCREEN IMAGE — Getting Started: Install / first launchgs_install.png
Updating from an earlier version? Install as an update through the Play Store — do not uninstall the old version and clean-install, which breaks the installation. After updating, on first launch the trail/track database is rebuilt: re-import your trails (1.2), and your recorded tracks return automatically from your saved GPX files (open the track import screen and tap RESYNC TRACKS if any are missing).
  1. Install GroupTrack from the Play Store internal-testing link the organizer sent you. [verify exact install path for testers]
  2. Open the app. Grant the permissions it requests — location (for your position on the map) and storage/files (for trail data and map tiles). On first launch the app prepares its on-device databases.
  3. If this is a fresh device (not an update), there is no trail data yet — continue to 1.2 to import trails for your area.
Requirements: Android 8.0+ (a tablet is recommended for map work). ~500 MB+ free for map tiles; trail data is roughly 15–30 MB per state. A radio (Meshtastic SenseCAP T1000-E or a LoRa device on firmware 2.6+) is only needed for convoy tracking, not for maps. Internet is needed once, to import trails and download tiles.

1.2 · Downloading trails

SCREEN IMAGE — Getting Started: Trail import (source / area)gs_download_trails.png

What you're doing: trail data is no longer bundled with the app. You import the trails for the regions where you ride, once, and they become permanent on your device.

  1. Open the Planning Map.
  2. Open Work with Artifacts and tap Import Trails. The trail source list appears.
  3. Choose a method:
    • Import by Source — select a land-management agency dataset (e.g. UGRC Utah Trails — ~49,000 trails + ~591 trailheads).
    • Import by Area — draw a box on the map and see the sources that overlap it, with overlap percentages. processing fix in progress
  4. On the validation screen, review the trail count and file size, then confirm to download. Trails and trailhead waypoints download as artifacts.
  5. Fully close the app (force stop) and reopen so the new trail data loads.
If imported trails don't show: (1) fully close and reopen the app so trail data loads; (2) zoom in — trails draw at zoom level 8 and above, so a large dataset only appears when you're zoomed in enough. This is intentional for performance.

Full detail in Chapter 4 (Work with Artifacts).

1.3 · Adding / updating map sources

SCREEN IMAGE — Getting Started: Map sources / tile settingsgs_map_sources.png

What you're doing: map sources are the base imagery behind your trails (satellite, topo, outdoor, etc.). V2.5 offers 16 sources across 6 categories, and any source can be assigned to any of the three toolbar slots (SAT / TOPO / TOPO+).

  1. Open Settings > Map Sources. [verify menu path]
  2. For each toolbar slot (SAT / TOPO / TOPO+), choose which of the 16 sources to assign.
  3. For premium sources that require an API key (e.g. Thunderforest), enter the key when prompted; keys are stored locally on the device.
  4. Changing a source triggers a background tile refresh for the new imagery.
Offline tiles: download tiles while you have internet so they're cached for offline use in the field. Tiles are served from your offline cache when available. See the Download Queue (Chapter 3) for managing tile downloads.

1.4 · Adding / updating trail sources

SCREEN IMAGE — Getting Started: Trail source cataloggs_trail_sources.png

What you're doing: beyond your first import (1.2), you can add more trail sources as you ride new areas, or update existing ones. Multiple sources and agencies can be active at once.

  1. Open Work with Artifacts → Import Trails to return to the trail source catalog.
  2. Add a source: pick another agency dataset (by source) or draw a new area (by area) and import, exactly as in 1.2.
  3. Update a source: re-importing a source you already have is de-duplicated — trails already on the device are recognized and skipped, so re-import is safe and only adds what's new. [verify trail-source re-import dedupe state]
Agencies: UGRC Utah Trails is the first catalog source; BLM and USFS are planned.

1.5 · Setting up your radio (optional)

SCREEN IMAGE — Getting Started: Radio setup / pairinggs_radio_setup.png

What you're doing: the radio is only needed for live convoy tracking — maps, trails, and routes all work without it. If you're riding solo or just planning, you can skip this.

  1. Power on your Meshtastic device (e.g. T1000-E).
  2. Open the Convoy Map and open the connection panel (Chapter 3). Pair the device over Bluetooth; the panel shows connection state.
  3. Apply the convoy radio configuration so all riders share the same channel and encryption — see Chapter 5 (Convoy Radio-Write Menu): Apply / Archive / Restore.
  4. Confirm the mesh is up in the monitoring panel before relying on positions.
Device compatibility: some budget Android devices cannot hold a stable Bluetooth link to the radio (the connection drops after several seconds). If positions stop updating and the panel shows repeated disconnects, the device may be incompatible — see the tester compatibility list.

2 · Planning Map

Screen: Planning Map · ? help anchor: #planning-map
SCREEN IMAGE — Planning Map (landing)planning_map.png

The Planning Map is the off-radio workspace: explore downloaded trails, import your track history, build and save routes, and manage what's displayed — all without a radio connected. It shares the spatial database and route engine with the Convoy Map, but keeps its own display state.

Map basics

  • Pan / zoom: drag to pan, pinch to zoom. These stay live at all times, even while building a route.
  • Base layers (SAT / TOPO / TOPO+): switch imagery from the layer control. Tiles are served from your offline cache when available. (Assign sources to these slots in Settings > Map Sources — see 1.3.)
  • Viewport-aware display: trails, tracks, waypoints, and routes load for the area you're viewing. Zoom in to see more detail; the display fills in as you move.

Displaying trails, tracks, waypoints, routes

See Chapter 4 (Work with Artifacts) — the toggle/select/edit controls are shared and documented there.

Too many trails in view: if the current view contains more trails than can be displayed at once, the SEL/Edit control indicates "Too many trails in view — zoom in to reduce." Zoom in to narrow the area until trails become selectable. guidance behavior — coming

Building a route

See the full cookbook entry in Chapter 4 → Creating a Route. Route building works identically on the Planning Map and the Convoy Map.

Importing trails / tracks

  • Import tracks (GPX): bring in your recorded track history. Large files import via streaming; duplicates (same geometry) are skipped automatically, and a recap shows new vs. already-in-library.
  • Import trails by area: draw an area to list and download trail sources overlapping it. processing fix in progress
Coming: waypoint and route extraction from GPX (all GPX imports are currently treated as tracks); GPX/KML open-with handler.

3 · Convoy Map

Screen: Convoy Map (incl. Meshtastic connection / monitoring panel) · ? help anchor: #convoy-map
SCREEN IMAGE — Convoy Map (landing)convoy_map.png

The Convoy Map is the live group-tracking screen used during a ride. It shows your position and the positions of other riders relayed over the Meshtastic LoRa mesh, plus the same trail/track/waypoint/route display and route-building tools as the Planning Map.

Connecting to your radio (connection & monitoring panel)

  • Connect: open the connection panel and pair your Meshtastic device (e.g. T1000-E) over Bluetooth. The panel shows connection state.
  • Monitoring: the panel reports link status and node activity. Use it to confirm the mesh is up before relying on positions.
Device compatibility: some budget Android devices cannot hold a stable Bluetooth link to the radio (the connection drops after several seconds). If positions stop updating and the panel shows repeated disconnects, the device may be incompatible — see the tester compatibility list.

Live tracking

  • Rider positions: other riders appear as node markers, updated as mesh packets arrive.
  • Your position: driven by the phone GPS once location permission is granted.

Waypoints

  • Drop a waypoint: long-press the map to drop a waypoint pin.
  • Pin shape: waypoints display as teardrop pins — the pin's point marks the exact location you dropped it. Each waypoint type has its own color and icon.
  • Proximity: waypoints within 100 m are treated as the same location.

Help on this screen

  • ? help: tap the ? button on the Convoy Map to open the release notes or the full user manual. (The same help is on the Planning Map; both open the same documents.)

Download QUEUES (tile downloads)

SCREEN IMAGE — Download Queues monitorqueues_download.png
  • QUEUES: opens the live download monitor (top-right) showing tile-download progress.
  • Manage the queue: hold (pause all processing, resume when ready), cancel a single entry, or cancel all. Downloaded tiles are preserved when you cancel a partial download.

Building a route on the Convoy Map

Identical to the Planning Map — see Chapter 4 → Creating a Route.

4 · Work with Artifacts

Screen: Work with Artifacts (shared by both maps)
SCREEN IMAGE — Work with Artifacts panel (landing)work_with_artifacts.png

"Work with Artifacts" is the control center for everything you display and create on the map: trails, tracks, waypoints, and routes. The toggle and select/edit controls are the same on the Planning Map and the Convoy Map.

Display toggles (ON / OFF / SELECTED)

  • ON: show all artifacts of that type in view.
  • OFF: hide that type.
  • SELECTED: show only the items you've checked in that type's select/edit list.

Select / Edit list (per type)

  • Open a type's SEL/Edit list to check individual items for SELECTED display, or to open an item's detail.
  • Search by name: choose an artifact type, type a name, and press Enter to find matching trails, tracks, waypoints, or routes by name across your whole database (not just what's on screen). Search is case-insensitive and matches partial names. Tap a result to open its detail.
  • Item detail: tapping an item's name (from a search result or the select/edit list) opens its detail card. The left side lists the actions available for that item's type; the right side shows the item's information. For trails this includes designated uses, surface type, classification (carto code), county, managing agency, and data source. Less-used technical values — bounding coordinates, created/updated dates, and the geometry hash — are tucked under a ▸ technical toggle so the useful information shows first; tap it to expand. Where a trail has alternate names on record, they appear here too. On the Convoy Map the detail is view-only; full editing is on the Planning Map.
  • FIT (fit to map): from an item's detail card, tap FIT to frame that item on the map. The map flies to the item and zooms to fit it, the item is selected and drawn on its own, and the other artifact types are turned off — so you see just the one you picked. Works for trails, tracks, waypoints, and routes, on both maps. FIT is how you go from finding a name to seeing it on the map.
  • List limit: the list currently shows up to 200 items. paging — coming
  • Trails over-limit: when more trails are in view than can be shown, SEL/Edit shows "Too many trails in view — zoom in to reduce." coming

Track display

Tracks display as dashed green lines from your device's spatial database. When Tracks are on, each track shows direction-of-travel arrows along the line so you can read which way it runs — useful for telling a single looping track from two overlapping ones. The arrows are evenly spaced on screen and stay readable as you zoom, and are drawn in the same neon green as the track.

Routes display

Routes display as magenta lines, loaded from your device's spatial database the same viewport-aware way as trails and tracks. Build a route with + ROUTE (see Creating a Route). (Importing routes from GPX, and the Draw / Suggest build methods, are coming in upcoming updates.)

Creating a Route (early access)

A route is a planned path you build by tapping the map, then save with a name for later use. Route building works on both the convoy map and the planning map.

  1. Open the map (convoy or planning).
  2. Open "Work with Artifacts" and tap + ROUTE. The Route+ toolbar appears.
  3. Tap New. A "Name this route" box appears with a suggested name — accept it or type your own — then start building.
  4. Add is on by default (green): tap the map to drop points. If a trail or track is nearby, the point snaps to it and the magenta route line follows the trail's actual shape between your points — so the route traces real trails instead of cutting straight across. Tap away from any trail to place a free point exactly where you tapped. Tip: zoom in while building for the most reliable snapping.
  5. Use Undo to remove the most recent point.
  6. Pan and zoom freely between taps to position the map.
  7. Tap Save to store the route. It is saved on your device, redraws on the map in magenta, and appears in Work with Artifacts → Routes under the name you gave it.
  8. Tap Discard to leave without saving.
Coming next (not in this build):
  • Save In Progress / Resume: save a half-finished route and re-open it later to keep editing (the "In Progress" entry).
  • Draw and Suggest build methods (placeholders today).
  • Renaming/editing a saved route from the Routes list (route maintenance).
Route maintenance (rename, edit geometry, delete a completed route) lives in Work with Artifacts → Routes (SEL/Edit), not in the Route+ toolbar. The toolbar is for building only.

Track / Trail / Waypoint maintenance

  • Per-type maintenance (rename, detail, delete) is reached from each type's SEL/Edit list. trail/route/waypoint maintenance — in progress

5 · Convoy Radio-Write Menu (Apply / Archive / Restore)

Screen: Convoy menu — radio configuration · ? help anchor: #radio-write
SCREEN IMAGE — Convoy Radio-Write menu (landing)radio_write.png
Transitional — current and supported in V2.5. These radio-configuration functions are how radio writes happen this release. They are slated to be replaced in 3.0, but they work now and you should use them. This manual fully covers them; the 3.0 manual will rewrite this section when the functions change.

Apply Convoy Config (write to radio)

  1. Connect the radio first (Chapter 3 connection panel) — the write action is unavailable with no Bluetooth link.
  2. Open the Convoy menu → radio configuration.
  3. Review the config values (channel, encryption keys, device settings). Values are validated before writing.
  4. Apply. The write proceeds screen-by-screen / in passes through the config groups; confirm each completes.
Field validation: the config is validated (e.g. full field check) before programming. A two-pass programming approach is used so all config groups are written and confirmed.

Archive radio config

  • Save the current working radio configuration so it can be restored later. Use this before making changes.

Restore radio config

  • Re-apply a previously archived configuration to the connected radio.
