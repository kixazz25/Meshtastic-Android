2. Description of Service

GroupTrack is a mobile application that provides real-time group position awareness over LoRa mesh radio, organized ride management, offline map navigation, and GPS track recording. The platform is designed for outdoor activities in areas without cellular service.

GroupTrack has two service categories:

  • Offline Services — convoy map, GPS tracking, offline tile display, radio configuration, GPX/KML file import. These work without an account or network connection.
  • Online Services — ride creation, invitations, enrollments, organizer broadcasts, community track sharing, and dashboard notifications. These require a signed-in account and network connectivity.
