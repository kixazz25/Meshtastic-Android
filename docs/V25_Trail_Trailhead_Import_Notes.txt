TRAILHEAD ASSET BUILD QUERIES
==========================================

Each trailhead source needs a one-time query to build
the bundled JSON asset. Normalize to standard schema:
  { "name": "...", "id": "...", lat/lon in coordinates }

UGRC UTAH TRAILHEADS (existing — utah_trailheads.json):
  Endpoint: https://services1.arcgis.com/99lidPhWCzftIe9K/ArcGIS/rest/services/Trailheads/FeatureServer/0/query
  Query: ?where=1%3D1&outFields=*&f=geojson&outSR=4326
  Field mapping: PrimaryName → name, TrailheadID → id
  Records: 591
  
  Normalize command (run once, save as asset):
  curl -o utah_trailheads_raw.json \
    "https://services1.arcgis.com/99lidPhWCzftIe9K/ArcGIS/rest/services/Trailheads/FeatureServer/0/query?where=1%3D1&outFields=PrimaryName,TrailheadID&f=geojson&outSR=4326"
  
  Then normalize PrimaryName→name, TrailheadID→id in the properties
  of each feature. Save as app/src/main/assets/utah_trailheads.json.

FUTURE SOURCES (when identified):
  Same pattern: find agency trailhead endpoint, query for geojson,
  map their field names to standard { name, id }, save as asset,
  add trailhead_asset field to trail_sources.json.

  Standard asset schema:
  {
    "type": "FeatureCollection",
    "features": [
      {
        "type": "Feature",
        "geometry": { "type": "Point", "coordinates": [-113.63, 37.19] },
        "properties": { "name": "Snow Canyon Trailhead", "id": "1234" }
      }
    ]
  }
