Installation & First-Time Setup

What Happens on First Launch

When you install GroupTrack for the first time, the app walks you through three steps before you reach the Ride Map:

  1. Permissions — GroupTrack needs access to your device's storage (for map tiles and trail data) and your location (for GPS tracking and state detection). The Authority Gate guides you through granting these.
  2. Home State Trail Data — GroupTrack detects your state from your GPS position and offers to download trail data for your entire state. This includes trails from multiple federal and state agencies plus Open Source Maps (OpenStreetMap). One tap starts the process.
  3. Ride Map — Once trail data is loaded, you land on the Ride Map with trails, scenic points, and places already on your map.

Home State Setup

After permissions are granted, GroupTrack checks whether trail data exists on your device. If this is a fresh install (no trail data), the Home State Setup screen appears automatically.

GPS Detection

GroupTrack uses your device's GPS and Android's reverse geocoder to determine your state. The screen shows:

"Based on your location, your Home state is New Hampshire"

Two options are presented:

  • LOAD [STATE] TRAIL DATA — starts the import immediately for the detected state
  • Select a different Home state — opens the full state picker list
📷 SCREENSHOT PLACEHOLDER: Home State Setup — GPS detection showing "Based on your location, your Home state is New Hampshire" with LOAD and Select Different buttons

State Picker List

If you tap "Select a different Home state" — or if GPS detection fails — you see the full state list. All 50 US states plus District of Columbia, Puerto Rico, and US Virgin Islands are available. California is split into California North (San Luis Obispo area and north) and California South (Santa Barbara/Bakersfield area and south) due to data size.

Type in the search box to filter. Tap a state to select it, then tap LOAD TRAIL DATA.

📷 SCREENSHOT PLACEHOLDER: State Picker List — showing searchable state list with one state selected and LOAD TRAIL DATA button

Import Processing

After tapping LOAD, GroupTrack processes every available data source for your state. A progress screen shows:

  • Source count and time estimate — "Processing 4 sources for New Hampshire — Est. ~28 minutes remaining"
  • Per-source progress — each source listed with step indicators:
    • ✅ = completed
    • ► = in progress (with detail like "23 MB of 129 MB" during downloads)
    • ○ = waiting
  • Running elapsed clock at the bottom
  • "Do not close GroupTrack while importing" — a blinking banner at the top of the screen

The import runs unattended. You do not need to interact with it — just leave GroupTrack open until it completes.

Data Sources

GroupTrack imports trails from multiple federal and state agencies. The exact sources depend on your state:

  • US Forest Service Trails — national forest trail systems
  • US Geological Survey National Trails — USGS trail database
  • National Park Service Trails — national park trail systems
  • Bureau of Land Management Trails — BLM managed routes and designations
  • State agency trails — varies by state (e.g. Utah Trails and Pathways, Arizona State Parks & Trails, Colorado Trail Explorer)
  • Open Source Maps — OpenStreetMap trail data via Geofabrik, including trails, scenic points (peaks, springs, cliffs), and places (towns, hamlets)

All sources are combined using a deduplication system that matches trails by geometry. When multiple sources have data for the same trail, GroupTrack keeps the most complete information from each source — a trail name from one source and surface type from another are merged into a single, richer record.

Completion

When all sources finish, a summary screen shows:

  • Each source name with its record count
  • Grand total of all records
  • Total elapsed time
  • An OPEN RIDE MAP button to proceed to your map

What if I Skip?

You can skip the Home State Setup. GroupTrack will open with an empty map — no trails, no scenic points. The setup will be offered again on your next launch. You can also import trail data later from the Map Features panel.

What if the Import is Interrupted?

If GroupTrack closes during an import (battery dies, app crash, phone restart), the import is automatically detected on next launch. GroupTrack will ask: "A trail import for [state] was not finished. Complete now?" Sources already completed are skipped — only the remaining sources are processed.

Import Trails (Map Features Panel)

After your initial Home State setup, you can import trail data for additional areas from the Map Features panel.

During development: accessible via "IMPORT OSM DATA" on the Map Features panel. After certification: renamed to "Import Trails" with state/area mode selector.

Import Trails by State

Tap Import Trails on the Map Features panel, then select BY STATE. The state picker appears (same as the first-time setup). Select a state and tap LOAD. All sources for that state are processed.

Use this when you're planning a trip to a new state and want complete trail data before you go.

Import Trails by Area (Coming Soon)

Tap Import Trails on the Map Features panel, then select BY AREA. The Ride Planning Map opens with bbox drawing enabled. Draw a rectangle over the area you want trail data for. All sources that intersect your drawn area are processed — if your rectangle crosses state lines, multiple Geofabrik state downloads are included automatically.

Use this when you want trail data for a specific riding area rather than an entire state.

Quickstart — First-Time Setup

  1. Install GroupTrack from the Google Play Store
  2. Grant permissions — tap through the Authority Gate to grant storage and location access
  3. Load your Home State — GroupTrack detects your state and offers to download trail data. Tap LOAD. This takes 3–10 minutes depending on your state and internet speed.
  4. Open the Ride Map — once trails are loaded, tap OPEN RIDE MAP. Your map now shows trails, scenic points, and places from multiple data sources.

That's it. You're ready to plan a ride. Tap any trail on the map to see its details, or use the Route+ planner to build a route.
