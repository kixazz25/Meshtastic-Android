GroupTrack V2.5 — Release Notes
Updated: May 25, 2026
=====================================

SPATIAL DATA ENGINE
- National trail database: 64,000+ trail segments loaded
  from UGRC Utah data (GeoPackage format)
- Viewport-based lazy loading: only loads visible data
- Preload architecture: data ready before toggle, instant
  show/hide with no loading delay

DISPLAY TOGGLES
- Four artifact types: Trails, Tracks, Waypoints, Routes
- Independent toggles in Work With Artifacts panel
- Preloaded data — instant visual response
- Legend with visual indicators per type

GPX IMPORT
- Import GPX files containing tracks, waypoints, and routes
- Automatic parsing of <trk>, <wpt>, <rte> elements
- Tracks saved as GPX files + spatial DB entries
- Waypoints mapped to 10 standard types (trailhead, fuel,
  gate, hazard, scenic, water, camp, parking, rally, other)
- Import summary with counts per artifact type
- Resync button for track file synchronization

ARTIFACT LIST MANAGER (ArtifactListPanel)
- SELECT button opens list of artifacts in current map view
- Checkbox per item: control individual artifact display
- Select All / Deselect All for bulk operations
- Click artifact name: opens "Working with [name]" panel
- Type-specific maintenance functions:
  * Tracks: Rename, Delete, Share, Copy, Fix Date
  * Waypoints: Rename, Delete, Change Type
  * Routes: Rename, Delete
  * Trails: View Aliases (read-only)

DOWNLOAD QUEUE MANAGER
- QUEUES button on Planning Map header
- Live download queue with active/pending/completed status
- Cancel controls for individual downloads
- Empty state indicator

MAP FEATURES
- SAT/TOPO/TOPO+ tile source selection
- Trail color infrastructure (CartoCode-ready)
- Click-to-popup on all artifact types
- North indicator on both maps
