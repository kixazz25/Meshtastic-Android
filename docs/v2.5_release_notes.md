# GroupTrack — Version 2.5 Release Notes (What's New)
_Field Test Release · Map Feature Update · updated 2026-05-31_

## About this release
V2.5 completes the free map product: trail and trailhead data you can download straight onto your maps, plus a single, consistent way to show and hide Trails, Tracks, Waypoints, and Routes on both the Convoy Map and the Planning Map. FIELD TEST build — known rough edges listed at the end.

## Headline: Import Utah Trails Onto Your Map
The big addition is the trail source catalog — pull a full set of Utah trails + trailhead waypoints directly onto your maps as artifacts, no files to copy, no internet needed once down.

**How to import UGRC Utah Trails:**
1. Open Work with Artifacts (accordion button).
2. Select Import Trails. The trail source list displays.
3. Select UGRC Utah Trails.
4. Tap Validate/Confirm. Trails + trailhead waypoints download as artifacts.
5. Fully close the app, force close, reopen. Imported trails/trailheads now appear.

**If imported trails don't show:** (1) Fully close/reopen (or Force Stop) so trail data loads. (2) Zoom in — ~49,000 trails only draw at close zoom. Intentional (see Known Issues).

## What Else Is New
- **Trail source catalog** — browse + import. UGRC Utah Trails first (~49,000 trails + 591 trailheads). BLM/USFS planned.
- **One consistent artifact display** — Trails/Tracks/Waypoints/Routes show + hide the same way on both maps via one shared process.
- **Independent map selections (NEW)** — Convoy and Planning maps each keep their OWN selections, saved across restarts. No longer carries between maps.
- **SELECTED shows exactly what you pick (NEW)** — SELECTED draws only checked items, consistent on both maps.
- **Drop waypoints on the map (NEW)** — long-press empty ground → 12 types (hazard, gate, water, fuel, shelter, trailhead, viewpoint, campsite, parking, junction, rally, other) + optional name. Appears on both maps.
- **Work with Artifacts panel** — accordion; per-type ON/OFF/SELECTED + item list.
- **Default on launch** — Trails ON, others OFF.
- **RESYNC TRACKS** — rebuilds track list from saved GPX.
- **Zoom readout** — compass shows zoom level (N · Z##).
- **Standalone GPS / offline maps** — carried from V2.4.

## Requirements
- Android 8.0+ (tablet recommended). Auto-update via Play Store internal track. 500MB+ free for tiles (trail data ~15–30MB/state). Meshtastic SenseCAP T1000-E or LoRa fw 2.6+ (only for convoy, not maps). Internet needed once to import/download.

## Known Issues — Please Read
- **Trails not visible zoomed far out** — expected; zoom in. Clean cutoff being finalized.
- **Item list sometimes shows no names** — known; being addressed.
- **Don't import the same trails/tracks repeatedly** — re-import can add duplicates (dedupe check coming). Import UGRC ONCE; use RESYNC TRACKS if something looks off.
- **Tracks missing after update** — RESYNC TRACKS rebuilds.

**Resolved since last build:** map selections are now independent per map and saved — the earlier "selections carry between maps" behavior is FIXED.

## Troubleshooting
- Imported trails don't appear → zoom in; confirm import finished.
- No vehicles (convoy) → radio connected (green)? same channel + PSK?
- Tiles blank offline → download tiles while online first.
- Tiles not loading online → check internet.
- Track missing → RESYNC TRACKS.
- Anything else → report it (note what you tapped + expected).
