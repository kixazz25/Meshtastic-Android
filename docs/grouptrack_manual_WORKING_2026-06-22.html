How this manual works. Each flow is one complete path to a function, start to finish — no page-flipping. A function reached several ways appears once per route; the badge shows how many panels deep it is. Type in the filter to jump to any screen or function. 43 total capture steps across the three sections. Each step’s command writes a screenshot to D:\grouptrack_screenshots. V2.5 only — the Release 3.0 account/dashboard/ride-management screens (moving to the cloud web app) are not documented here.
