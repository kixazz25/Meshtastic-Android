3 · 🔴 Blocking riders — fix before anything else

IMPORTLOCK — the importer can be bricked, and a rider cannot clear it. ⭐ Root cause ISOLATED 09-20: it is beginImport()'s IN-MEMORY LATCH at HomeStatePickerScreen:133, NOT the stranded manifest. A dead run leaves the latch set and nothing launches — no message, no log. Force-stop alone frees it. Fix is 2.6g, two parts: release the latch, then SRCLIST — list the state's sources, tick what is already held (bypassed), untick to pull one back in. ⭐ SRCLIST subsumes the resume prompt entirely: a failed source simply arrives unticked, so "resume" is pressing import again. ⚠ Make the tick an ACTION, not a status — the maps checkbox had exactly that ambiguity and it cost a day.

Why it pays: the Utah rerun fetched 49,125 records to insert 52, for 27–31 minutes. A rerun pays the full cost for almost none of the benefit — and area downloads over a held state have the same problem.

7 · Rules a new conversation must not break

  • ⛔ The convoy map is FROZEN — ConvoyScreen.kt is not edited. The MENU (ConvoySubMenu from ui/Main.kt) and the planner are not frozen.
  • Leader = organizer = a role on the profile. Several orgs per rider. In 2.7 the leader of a ride you create is ALWAYS you.
  • Networks generated in exactly three places — org added · leader chooses "my own" · a unique ride network. GT id + 32-byte key + base values, TX at or below the licence-free limit. Immutable; rotation makes a new one. ALWAYS write both mesh and nucleus blocks.
  • ONE WRITE PATH — profile maintenance creates every rider, org, leader setting and network.
  • Other people exist only as ride data. Callsigns may repeat; riders matched by DEVICE (tak_uid, or node_num).
  • Four role rules — single holder · release then claim · only a person changes a role (a quiet radio means nothing) · leaving releases it.
  • Only ROUTES travel, distilled to a polyline. Identity is (type, geom_hash), never the hash alone.
  • Nothing written until Save. No ghosts.
  • Nothing is sent to GroupTrack unless the rider shares — and sharing sends only their ride and their email.
  • ⛔ No OSM-derived data on GroupTrack infrastructure, ever. ⚠ This may exclude the route RECIPE from ride files — check what readRouteNotes actually holds before building the writer.
  • CODE RULES 1–3 and the GOLDEN RULE (never reuse a filename) — see the master.
