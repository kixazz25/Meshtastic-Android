CHAPTER 6: WORK WITH ARTIFACTS

6.1 Overview
The Work With Artifacts panel provides access to four spatial
data types: Trails, Tracks, Waypoints, and Routes. Each type
has three controls: Display (toggle visibility), Select (list
and filter individual items), and Import.

6.2 Display Toggles
Tap the toggle circle next to any artifact type to show or
hide it on the map. Data is preloaded — toggling is instant
with no loading delay.

Toggle states:
  Gray circle: OFF — type not displayed
  Blue circle: ON — all items of this type displayed
  Yellow circle: ON — partial display (filter active)

6.3 Importing Artifacts
Tap IMPORT to add new artifacts from GPX files:
  - Trails: opens trail source management
  - All others: scans Downloads folder for GPX files

GPX files may contain tracks (<trk>), waypoints (<wpt>),
and routes (<rte>). All types are extracted and imported
in a single pass. Import summary shows counts per type.

Waypoint types are automatically mapped from GPX type tags:
  trailhead, fuel, gate, hazard, scenic, water, camp,
  parking, rally, other

6.4 Resync Tracks
The RESYNC TRACKS button rescans track files in the
my_tracks directory and synchronizes them with the spatial
database. Use after manually adding or removing GPX files.

6.5 Legend
The map legend shows visual indicators for each type:
  Solid line: Trails
  Dashed line: Tracks and Routes
  Pin marker: Waypoints

6.6 Artifact Popups
Tap any artifact on the map to see a popup with the
artifact name and type. Trail segments show the trail name.
Waypoints show name and waypoint type.

6.7 Select/Edit Artifacts
Tap SELECT on any artifact row to open the Artifact List
Panel showing all items of that type in the current map view.

List Controls:
  - Checkbox: check/uncheck individual items for display
  - SELECT ALL: check all items
  - DESELECT ALL: uncheck all items

Detail Panel:
Tap an artifact name to open the "Working with [name]"
dialog with available maintenance functions:

  Tracks:
    RENAME — change the track name
    DELETE — permanently remove the track
    SHARE — share track file (coming soon)
    COPY TO DOWNLOADS — save copy (coming soon)
    FIX DATE — correct track file date (coming soon)
    VIEW ALIASES — manage aliases (coming soon)

  Waypoints:
    RENAME — change the waypoint name
    DELETE — permanently remove the waypoint
    CHANGE TYPE — select from 10 standard types
    VIEW ALIASES — manage aliases (coming soon)

  Routes:
    RENAME — change the route name
    DELETE — permanently remove the route
    VIEW ALIASES — manage aliases (coming soon)

  Trails:
    VIEW ALIASES — manage aliases (coming soon)
    (Trails are read-only — sourced from agency data)

CHAPTER 7: DOWNLOADS

7.1 Download Queue Panel
Tap QUEUES on the Planning Map header to view the download
queue. The panel shows:
  - Active downloads with progress
  - Queued downloads waiting to start
  - Completed, failed, or cancelled downloads
  - Cancel button for individual downloads
When no downloads are in the queue, the panel shows
"No downloads in queue."
