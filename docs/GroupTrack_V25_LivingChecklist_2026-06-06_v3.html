B. Snap-2 — CONVOY MAP: DONE & PROVEN ON DEVICE

WIN Snap-2 now traces the route along trail/track geometry on the convoy map (ConvoyScreen.kt). Confirmed three ways: logcat (tracedLen grows far faster than vertex count as consecutive same-line snapped points fill in trail geometry — one run snapped 5→6 jumped tracedLen 709→2802 = a long trail slice; the pts= arrays contain intermediate trail vertices, not just taps), on-screen, and reproduced via undo/repost.

What was wrong & what fixed it

  • Confirmed (branch A): snap COMPUTES & STORES correctly. Draft JSON had vertices with "snapped":true, real lineId, lineType, segmentIndex, interpolation t. buildSegments() (RouteManager.kt:218) genuinely traces — walks consecutive pairs, sameLine = a.snapped && b.snapped && same lineId, slices the underlying line via sliceLine using pos=segmentIndex+t. Its ONLY caller was buildWktAndBbox (save-completed) — the draw paths bypassed it.
  • Fix: the live draw now runs the snapped vertices through buildSegments against the viewport geometry, swaps [lon,lat]→[lat,lon], and feeds drawBuildLine. Patched block: addVertex(v); val pts = withContext(IO){ init; queryTrails+TracksByViewport; byId(trail_id/track_id→geometry); buildSegments{ lineId→byId[lineId]?.let{ parseWktLine } }.joinToString swap [lat,lon] }; drawBuildLine(pts).
  • TWO handlers, both patched: ConvoyScreen has two onMapTap — site 544 in the if(existing != null) persistent-WebView branch, and site 694 in the else/factory branch. Fresh map sessions run the FACTORY (694) handler — patching 544 alone did nothing visible; the 694 patch is what made it work. (Recurring "two handlers" trap.) Patches: patch_v25_trailtrace_site1_544_v6.py, patch_v25_trailtrace_site2_694_v1.py.

Behavior notes (not bugs)

  • Snap catch-rate depends on ZOOM — radius is hardcoded 30.0 m real-world; zoomed out (~¼ mile) almost nothing snaps, zoomed in it catches reliably.
  • Trace only draws between TWO CONSECUTIVE snapped vertices on the SAME line — isolated or cross-line snapped points draw straight to their neighbors, by design.

Diagnostic logs retained in committed code: tracedLen at ConvoyScreen ~555 and S2 tracedLen at ~716. Harmless Log.d; strip at AAB prep (see §E).
