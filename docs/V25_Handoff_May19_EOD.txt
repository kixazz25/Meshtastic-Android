ISSUE 1: IMPORT HARD CRASH
  Status: UNRESOLVED — crash fix applied but not yet tested
  Symptom: App hard crashes immediately after tapping IMPORT ALL TRAILS on processing step
  Probable cause: TrailImporter.applyMigrationIfNeeded() queries schema_version table
    without try/catch. If table doesn't exist (first run, partial DB init), unhandled
    exception kills the coroutine and crashes the app.
  Fix applied: Wrapped rawQuery in try/catch, defaults to version=0 on failure
  File: TrailImporter.kt line ~applyMigrationIfNeeded function
  TEST FIRST TOMORROW: This is the #1 priority. If crash persists, the cause is elsewhere.

  Step 3a: A2_VALIDATE — shows source details (name, agency, format, scope, coverage, trail count)
