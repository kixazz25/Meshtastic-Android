Issue Impact Workaround

T1000-E BLE disconnect/reconnect loop on some Android devices Secondary Android only; primary devices stable Disable battery optimization; manually disconnect before leaving BLE range
Windows BLE + Python CLI sometimes fails to connect Intermittent on Windows Retry connection; close Web Client tabs first; ensure only one BLE client at a time

Risk Register

Risk Likelihood Impact Mitigation
Windows BLE connection unreliable Medium High Add auto-reconnect logic; test on Linux as fallback
T1000-E GPS slow to lock indoors High Medium Always start devices outdoors; document warm-up time
Meshtastic phone app map bug Confirmed Low Use ATAK or Python dashboard for visualization
T1000-E file system corruption from BLE drops Medium High Manually disconnect before leaving BLE range; keep firmware updated
LoRa range insufficient for convoy spread Low High Test actual range; switch to LONG_MODERATE preset if needed
Position broadcast interval too slow for real-time Low Medium Already configured to 30-60 sec; can reduce further if needed
