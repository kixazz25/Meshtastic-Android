4. Architecture Decisions Made Today

  • Manifest check for fresh install — hasCompletedImport() checks for completed JSON manifests in Documents/GroupTrack/imports/, NOT a DB query (DB may not exist on fresh install).
  • Geocoder for GPS detection — bbox matching fails at state borders (NH/MA overlap at 42.88°N). Geocoder returns actual state name. Bbox is fallback.
  • OsmImportLedger.create() MUST be called before setPendingImport() — the ledger silently returns null if no file exists.
  • Geofabrik -latest- URLs return 302 redirects — HttpURLConnection needs explicit redirect following.
  • Download progress requires MutableStateFlow not plain var for Compose visibility across threads.
  • collectAsState() must be hoisted above LazyColumn items block.
