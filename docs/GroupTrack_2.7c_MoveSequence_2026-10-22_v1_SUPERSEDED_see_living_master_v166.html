Why this document

Fred, 15:10: "we need a sequence to work with, specifying function and the order they are moved … maps killed us. We have a lot of map options that run only in automated functions — those do not belong on a menu … import maps by corridor is only an automated process … I would identify the functions we are moving and where they were located before, to help us with grouping. Map selection and source belong together."

  • Bring over as it exists, then restructure. Nothing is redesigned while it is moved (Fred 14:35).
  • Automated is not a menu item. A function that only runs inside another process (a corridor download after an import, a source refresh) is moved WITH its process and never gets a button.
  • Prune, then group. Once the complex processes are pulled out of the screens, what is left that a rider actually starts is what gets grouped on the menus.
  • Map selection and map sources belong together (one group).
  • Trace before attaching (10-22 lesson): any function that crosses into another screen is traced start → work → complete → cancel → back before it is handed over.

The order

  1. Phase 1 — Persistence in ONE MAP. ONE MAP gets its own state ("grouptrack"); every read/write uses the current map's key; every map's state is captured (view, layers + selections, map type, offline mode, stay-panels). The cold-launch delete goes. Start-up path mapped at the same time.
  2. Phase 2 — Route+ into ONE MAP. The planner's whole route process (row R1–R8 below) hosted on ONE MAP; Add Route launches on the map it is invoked from. Add Route testing here, before anything else moves.
  3. Phase 3 — the planner's rider-started map functions into ONE MAP (rows P1–P10), with the automated pieces they call (rows A1–A6) moving inside them.
  4. Phase 4 — the rest of the ride map into modules (rows M1–M10), so ConvoyScreen holds nothing ONE MAP needs; ConvoyScreen and the planner screen are retired.
  5. Phase 5 — start-up from ONE MAP's persistence. GroupTrack.kt becomes the start screen.
  6. Phase 6 — prune and realign. Remove Map Features and anything now duplicated; regroup the menus from what is left (Map type + Sources together).
