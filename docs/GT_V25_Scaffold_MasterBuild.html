STANDING RULES

  • Phase 0 scaffolding ships first. All UI placeholders before feature code.
  • One comprehensive patch per agreed design. Uniquely versioned Python.
  • Display name = COALESCE(preferred_alias, spatial.name, agency_id, 'Unnamed')
  • Every data change journaled via AuditLogger. No exceptions.
  • Never build V2.6 processing code during V2.5.
  • Never commit V3_FEATURES_ENABLED = true.
  • Install always -r -d. Build always -x uploadCrashlyticsMappingFileGoogleRelease.
