The three workstreams — each depends on the one before:

  1. Unbundle the mesh connection — the 2.7 separation (G15).
  2. Move the payload to TAK — V2 packets, the shared SDK (G13, G14, X2).
  3. Simplify the config to the transport fields — 48 fields down to 8, one apply process, snapshots instead of images (G6–G10).

Data structures

§A — Config (GroupTrack's library, G2)

{
  "format_version": 1,
  "config_id":    "GT7K2M9QXR",            // G1 — also the WiFi network name and the channel name
  "owner":        { "type": "org", "id": "<org uuid>" },   // org | leader | ride
  "display_name": "Iron County SxS",        // what riders read; shown with the last four: "· 9QXR"
  "created_at":   "2026-09-21T14:00:00Z",
  "network": { "ssid": "GT7K2M9QXR", "password": "<generated>" },
  "radio": {                                // the 8 transport fields (G9) — never owner/owner_short
    "region": "US", "modem_preset": "SHORT_FAST", "role": "TAK",
    "hop_limit": 3, "tx_power": 30, "frequency_slot": 0,
    "channel_name": "GT7K2M9QXR", "psk": "base64:<32 random bytes>"
  },
  "tak_sdk_version": "<pinned, X2>"
}

⚠ The same id is the channel name and the WiFi network name — frequency slot 0 then follows from the name on every node. tx_power never above the licence-free limit for the region.

  "format_version": 1,
  "ride": {
    "ride_id": "<uuid>", "name": "Sand Hollow loop", "date": "2026-10-03", "start_time": "09:00",
    "description": "...",
    "trailhead": { "name": "West lot", "lat": 37.1234567, "lon": -113.3456789 }
  },
  "route":     { "name": "Sand Hollow loop", "gpx": "<GPX 1.1, route only — tracks converted (G5)>" },
  "waypoints": [ { "name": "Lunch", "lat": 37.13, "lon": -113.36 } ],
  "maps":      { "mode": "corridor", "sources": ["SAT", "TOPO"] },
  "config":    { ...config JSON (A)... }  // login + radio config — STORED on import, applied when selected
}

⚠ Target shape. Inventory the current .convoy format first — riders already have files in it, so import must read both and format_version tells them apart.
