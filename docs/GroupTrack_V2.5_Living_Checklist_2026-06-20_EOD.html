⛔ Open tasks — UI data (finish these first; they complete the UI)

Open · pick up first

1 · FIT SEL/EDIT-panel row update (the one remaining FIT piece)

Decision already made — implement Option B. No re-diagnosis needed.
  • Symptom: FIT applies correctly (centers, selects, JSON perfect) but the SEL/EDIT panel is still open underneath. When that panel later closes, its launch-time state (all / none) takes precedence and overrides the FIT — the trail disappears or all artifacts show.
  • Why: FIT never writes the panel's row state. A manual row-select writes it (proven: manually selecting the same row you just fitted works); FIT does not. The viewport query always runs and applies off/on/selected — FIT just never sets the panel row to SELECTED + the fitted id.
  • Fix (Option B, chosen because it removes any user-interaction path that can break FIT state): on FIT / detail launch, close the SEL/EDIT panel and set its row + state to the one fitted artifact — i.e. selectedArtifactIds = setOf(fittedId) and activeListType = fittedType, plus showArtifactsPanel = false.
  • Where: ConvoyScreen onOpenDetail ~line 1292 and ~1780 (both set pendingDetail* but never close the panel). Mirror the manual-select row write found in commit 35ccccc4a ~lines 1678-1679 (selectedArtifactIds = …; activeListType = typeName). Apply to both screens.
