Rewrite of the Radio write processes:

Three distinct functions with their own rules

Function 1. Master config to Raadio
setup Json master config definitions
Use Android export functions to create binary master.cfg binary
Create rules checklist for field applies.
Process Save Radio Config to Archive using Export Configuration and creating binary backups by radio id with date and time and channelname
Apply the the Master config binarys to the radio. use the checklist to identify values to be updated and submit those indvidial updates.
When completed save this image in the archive local as cfg file using export config function

Function 2. Apply ride info to radio.
1) archive the current radio image using export process to create radio specific backup
2. read current radio image json
2) apply binary master file image to the radio.
3) use rules image function to identify fields that must change (Channel Name and encryption key are mandatory}
4) one finished the ride cfg is attach the ride. cfg file to the file for distribution
Distribute ride cfg via email
