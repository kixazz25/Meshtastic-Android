Cookbook · flow-per-path · PROOF: Convoy Map section · 2026-06-22
How this manual works. Each flow is one complete path to a function, start to finish — no page-flipping. The same function may appear under several flows (one per way to reach it); the badge shows how many panels deep it is. Type in the filter to jump to any screen or function. Screenshots are captured per step (the command under each step writes to D:\grouptrack_screenshots).

1. Convoy Map

The live ride view — your group’s vehicles in real time. Everything below is reached starting from the Convoy Map. On the Convoy Map the Work with Artifacts panel is display-only (no editing or import during live operations).
Convoy Map (the live map)1 panels
Convoy Map
Convoy Map
Your group’s vehicles in real time. The right-edge icon column gives you Search, Work with Artifacts (display-only), and Help. Header shows the tile source, QUEUES, and the zoom readout (N · Z##). Track direction shows as pixel-spaced neon arrows.

Search

Search (from Convoy Map)2 panels
Convoy Map › Search
Search (Universal)
Tap the search icon to open one search across five modes — Area · Track · Route · Trail · Waypoint. Pick a mode, type, and search.

Artifact Detail (via Convoy › Search)3 panels
Convoy Map › Search › (result) › Detail
Artifact Detail Panel
Tapping a search result opens the unified detail panel — rider-facing details, a collapsible technical section, and actions (rename, change type, share, delete, and FIT). For trails it shows the Carto Type band.

Convoy Map › Search › Detail › FIT
FIT — recenter to artifact
FIT recenters and zooms the map to frame the selected artifact with a small margin, keeping it selected. Jump straight to what you searched for.

Work with Artifacts (display-only)

Work with Artifacts (from Convoy Map)2 panels
Convoy Map › Work with Artifacts
Work with Artifacts (display-only)
Tap the Work with Artifacts icon to open the panel. On the Convoy Map it is display-only — toggle Trails / Tracks / Waypoints / Routes on or off. Each type has the three-state control: ON (all in view), OFF (hide), SELECTED (only checked).
