2 · Design changes this forces or allows

  1. No box records, no Wi-Fi credentials in GroupTrack (Fred, 09-24). Riders join a box's Wi-Fi the ordinary Android way; GroupTrack finds the box through the current network's gateway (10.20.<id>.1) and /api/v1/version. The ride file's nucleus.ssid and nucleus.password are removed; the Wi-Fi word-password idea retires.
  2. A ride changes only the box's RADIO (channel, key, LoRa values, owner) through /api/v1/meshtastic/config/apply, key sent as base64:…. The box's Wi-Fi and mesh link are the owner's and are never touched — the guest model.
  3. No boot profiles, and none needed: the box's config persists until changed, so "last used" survives reboots (the lunch-stop case is solved), and "return to owner" is an explicit action: GroupTrack reads the radio config before a ride (the restore point) and re-applies it afterwards.
  4. Identity of bridged reports comes from the CoT uid, not the Meshtastic from. The port-257 / IP translators key a rider by their TAK uid (tak- + hash), linked to a node number when that rider is also heard directly.
  5. A CoT translator is required for anything the Nucleus relays (port 257, or whatever he confirms): read uid, callsign, point, track — assign through the same position function. Speed is m/s; altitude stays HAE (label it, or convert for display).
  6. The bridge must carry GroupTrack's traffic both ways (he is open to it): today it moves ATAK's CoT only, so riders on LoRa sending TAKPacket (port 72) or plain position (port 3) may never reach riders on the box's Wi-Fi. Ask: bridge 72 and 3 into CoT on Wi-Fi, and CoT into 72 on LoRa.
  7. Preset per ride is real: a ride that includes a Nucleus with voice runs SHORT_FAST; T1000 range drops sharply there. The ride's preset decides it; the organizer sees the trade.
  8. The replacement standalone radio = a small Nucleus configured through the same HTTP API (via its AP) or USB — so GroupTrack's Nucleus apply covers it; no Bluetooth path needed for that unit.
  9. Remote access = a GroupTrack tailnet (his offer): Tailscale on the organizer's tablet; decide who owns it.
  10. Our Bluetooth/USB apply for plain radios stays ours (no code sample to copy): same eleven fields, same read → apply → confirm shape.
