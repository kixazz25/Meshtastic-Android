GroupTrack — Quick Start
QUICKSTART-2026-08-27-v12 · V2.6h · tick as you go

Work down the list. Each item says what to do and where the manual explains it. Sections marked optional can be skipped.

1 · Install

Check your tablet is supported
Android 10 or later, and enough free space for offline maps.
Manual → Installation & First-Time Setup → Device Compatibility
Install the GroupTrack APK
Sideloaded for closed testing. Allow installs from your browser or file manager when asked.
Manual → Installation & First-Time Setup → Installing the APK

2 · First launch

Grant all-files access
Maps are 50–60 GB and live in shared storage so they survive updates and reinstalls.
Manual → Installation & First-Time Setup → Your first launch
Grant location access
Puts you on the map and records your tracks.
Manual → Installation & First-Time Setup → Your first launch
Load your home state's trails
The app works out which state you are in and offers it. One tap starts it.
Manual → Installation & First-Time Setup → Home State trail data
Confirm the Ride Map shows trails
Trails, scenic points and places should be drawn when the load finishes.
Manual → The Ride Map

3 · Your Meshtastic radio — optional

GroupTrack works without a radio. The radio shares live positions between riders where there is no cell signal.

Flash the supported firmware version
⚠ Two restrictions apply and both matter — read them before pairing.
Manual → Radio → Firmware reference
Pair the radio over Bluetooth
One radio per tablet.
Manual → Radio → Setup
Write the ride configuration
Channel, region and role, set from the app.
Manual → Radio → Setup

4 · Tracks from another app — optional

Export your tracks as GPX from the other app
onX, Gaia, Trailforks and handheld GPS units all export GPX.
Manual → Artifacts → Importing tracks
Import them into GroupTrack
Nothing is overwritten, and the same file imported twice does not duplicate.
Manual → Artifacts → Importing tracks

5 · Maps

Choose your map source
SAT for satellite imagery, TOPO or TOPO+ for contour detail.
Manual → Map Sources → changing a source
⚠ Changing the source later affects tiles you have already downloaded. The manual explains the three ways that can go and which one you want.

6 · Download maps before you go off grid

Do this at home, on wi-fi. Once you leave coverage the map only shows what is already on the device.

Download the area you are riding
Draw a box around the riding area and queue it.
Manual → Downloads → by area
Download the corridor you are driving in on
The route to the trailhead is not covered by the riding-area box.
Manual → Downloads → by corridor
Let the queue finish before you leave
Progress and remaining tiles are shown while it runs.
Manual → Downloads → the download queue
Check your battery settings allow long downloads
Aggressive power management can pause a queue overnight.
Manual → Downloads → long downloads and battery settings

7 · Plan a route

Plan from where the trails start, not from town
⚠ The imported trail data contains roads as well as trails and cannot yet tell them apart — plan from inside a town and the rides offered will follow streets.
Manual → Planning → choosing a staging point
Set your distance and pace, then let the app find rides
It returns several routes, each drawn in its own colour.
Manual → Planning → finding rides
Compare them in the table and keep the ones you want
Rows are places and trails; the most-used trails sort to the top, so rides built on the same backbone are easy to spot.
Manual → Planning → comparing suggested routes
