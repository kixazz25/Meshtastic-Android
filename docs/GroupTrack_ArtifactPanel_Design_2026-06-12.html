One composable · four configs

What changes by artifact type

The frame is identical; the function list and full-data fields swap per type. Delete rules are enforced against real reference columns verified in the schema.

TRAIL

trail_properties
Functions: Rename · Fit to display · Show aliases · Delete (blocked — agency)
Data: class · carto code · motorized · surface · steward · county · distance · agency

TRACK

track_properties + track_surveys
Functions: Rename · Fit · Aliases · Convert to route · Survey · Delete*
Data: distance · duration · max/avg speed · elevation · points · survey

WAYPOINT

waypoint_properties
Functions: Rename · Fit · Aliases · Edit · Delete**
Data: elevation · description · source format · source file

ROUTE

route_properties
Functions: Rename · Fit · Aliases · Set trailhead · Delete***
Data: distance · method · trailhead · elevation · description
  • Delete guards (checked against verified reference columns): Trail — never deletable (agency-owned, agency_id/data_source set). Track* — warn if a route's source_track_id references it. Waypoint** — block if a route's trailhead_id references it. Route*** — block if route_properties.ride_id is not null.
  • Delete cascade (when allowed): remove the row's *_properties, its artifact_aliases, any track_surveys, queue entries, and write a data_log entry (before/after state).
Alias accordion

Preferred name, sources, and what's deletable

  • Preferred (★) = the alias shown as the artifact's display name on the map. Exactly one per artifact, local only. There's no DB constraint enforcing this — when the user stars an alias, the code clears the other is_preferred flags for that artifact in the same transaction.
  • Source chips read from artifact_aliases.source: agency and aws aliases are undeletable; user aliases are deletable — unless it's the only alias left (minimum one).
  • Records are dated (created_at / creation_date) and shown newest context first. Adding an alias is blocked from creating a duplicate name by UNIQUE(artifact_type, artifact_id, alias).
  • Write path: add-alias calls SpatialDbManager.addAlias(type, id, name, geomHash, creationDate) via ConvoyArtifactOps.addAlias(...). (AliasManager.kt is an empty stub — do not wire to it.)
