  - SAT/TOPO tile downloads succeed
  - Directory TOPO+ exists and is writable (verified with touch)
  - buildTileUrl does NOT use sourceName (URL is identical)

WHAT FAILS:
  - CalTopo HTTP downloads return non-successful response
  - No exception thrown (catch block not triggered)
  - No "Tile fail" log (exception path not hit)
  - The response.isSuccessful check returns false → returns false → counted as failed

PENDING FIX (applied to source, not yet built):

  Build command:
    ./gradlew assembleGoogleRelease -x uploadCrashlyticsMappingFileGoogleRelease

THEORY:
  CalTopo S3 may reject non-browser User-Agent. OkHttp default
  User-Agent is "okhttp/4.x". WebView sends Chrome User-Agent.
  The downloadTile function does NOT set a User-Agent header:
    val request = Request.Builder().url(url).build()  // no headers
  
  Fix would be: add User-Agent header matching what WebView sends.
