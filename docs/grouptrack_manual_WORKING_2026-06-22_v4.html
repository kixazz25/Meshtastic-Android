Cookbook · flow-per-path · one screenshot per panel · 94 captures · 2026-06-22
How this manual works. Each flow walks one complete path, one screenshot per panel — a 4-panel flow has 4 commands. A function reached several ways appears once per route. Within a flow, use the same artifact at every step so the screens stay consistent. 94 total captures across the three sections. Each command writes to D:\grouptrack_screenshots. V2.5 only — Release 3.0 account/dashboard/ride screens (moving to the cloud web app) are not documented.
