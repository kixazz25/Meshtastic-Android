Requests

#RequestWhy
R1The relay interval as a setting, readable and writable through the API (config.yaml), set BELOW the sender's rate — e.g. 2 s for GroupTrack's 3 s — so every GroupTrack report passes and only faster senders are limited.A1/A2. A cap EQUAL to the sender's rate aliases: jitter drops about half the reports and doubles the apparent age (3 s becomes ~6 s, ~9 s with the receiver's tick).
R2Movement-aware relaying (optional, later): relay when a rider has moved more than N m, never faster than the interval, slowly when parked.Keeps the LoRa channel quiet at stops; the ATAK "dynamic reporting" idea.
R3Bridge GroupTrack's LoRa traffic onto the Wi-Fi: port 72 (TAK PLI from T1000s in TAK_TRACKER / from the GroupTrack app) and port 3 (plain position) → CoT on the SA multicast.Today the bridge carries port 257 only; GroupTrack riders on LoRa would be invisible to riders on the box's Wi-Fi.
R4Publish the TAK SDK / compressor version the bridge uses (e.g. in /api/v1/version).GroupTrack must decompress port-257 TAKPacketV2 exactly as the bridge compresses it; a version mismatch must be detectable.
R5Add a ride's channel as a SECONDARY channel on the box radio (keep the owner's primary).GroupTrack as a guest: a ride never displaces the box's normal use.
R6Confirm whether a second tablet can use the box radio (TCP 4403) while the bridge holds it.The bridge "owns the radio exclusively".
R7Per-ride control of voice on LoRa (ports 256 / 260).Voice shares the ride's airtime; a ride may want it off.
R8Two APs at once (owner's + ride's), if the AP radio allows.Guest model, optional.
R9Config API authorization: a key required on every WRITE endpoint (config, apply, radio apply, channel URL, join-peer); READ endpoints stay open; an initial key per box set at provisioning (label / QR); a reset path back to it.Today anyone on a box's Wi-Fi can rewrite its config (their issue #2). GroupTrack will hold the key on the organizer's tablet only (encrypted) — NEVER in a ride file.
R10The radio-only unit (Pi Zero 2, 30 dBm, GPS, AP/USB config): spec, antennas, 12 V + battery, OHV housing, cost, lead time.T1000-E replacement.
R11A joint saturation test: presets × group size × 3–5 s, measured.Sets the real interval per preset.
R12Key management — two keys. (a) An owner key, rotatable by its holder through an authenticated set-key endpoint; the old key stays valid until the new one has been used once (no lockout). GroupTrack receives the initial key once, then generates and reassigns keys as part of reconfiguring a box. (b) A separate Natak support key for remote support, not changeable by the owner's tools. The owner can switch support access on and off; each write is logged with the key that made it.Fred 09-24. Rotation/reassignment lets a box pass between organizers safely; the support key keeps Natak able to help without a permanent back door.
