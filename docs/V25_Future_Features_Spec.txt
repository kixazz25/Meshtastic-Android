GroupTrack V2.5+ — Future Feature Specifications
Updated: May 26, 2026
==========================================

FEATURE 1: CORRIDOR ROUTE PLANNING
==========================================
User drops start/end points (town names or map taps).
System calculates 50-80 mile corridor, finds ALL viable
trail routes, displays multiple options for comparison.
User selects preferred route or combines sections.
See: V25_Route_Planning_Spec.txt for full details.

FEATURE 2: RIDE PREVIEW (TERRAIN SCRUBBER)
==========================================
Interactive terrain preview along planned route. User
scrubs through route at own pace using slider. Satellite
terrain snapshots every 300ft. Elevation profile strip.
Waypoint alerts. Works offline from cached tiles.
Use case: field rerouting — preview alternate paths
before committing.

FEATURE 3: 3D TERRAIN VIEW
==========================================
Cesium.js or Mapbox GL 3D terrain with route overlay.
Fly-through animation. Premium tier feature (V3.0).

FEATURE 4: PROXIMITY TAP
==========================================
[IN CURRENT BUILD]
Tap overlapping artifacts → all nearby labels show 4 sec.
Eliminates precision tapping on narrow trail lines.

FEATURE 5: SHORTEST PATH
==========================================
A* algorithm on trail network graph (64K segments).
Two-point tap → shortest trail path calculated.
See: V25_ShortestPath_FeatureSpec.txt for full details.

FEATURE 6: GPX BUILDER
==========================================
[DEFERRED — syntax errors in initial implementation]
