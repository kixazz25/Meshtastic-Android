How the doc set works

Living documents are EDITED IN PLACE and re-versioned — the new version contains everything the old one had, plus the day's work. So the highest version number is always the complete one, and older copies can be ignored.

The handoff is the exception: it is rewritten each time, which is why it must carry every open item forward. v1 today did not; v2 does.

Filenames are never reused — a correction gets a new version number, because Windows appends "(1)" to a duplicate download and the wrong file gets run.

Today's design and every decision reaches the LIVING MASTER, not just a side document — a living doc that only references an external file is no use if that file is lost.
