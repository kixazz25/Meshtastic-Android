DESIGN DECISIONS THIS SESSION
==========================================

DECISION: Artifact Identification Approach
  GOAL: Users need to identify overlapping artifacts to reduce clutter
    during route planning.
  REJECTED: JS proximity tap (4 hours, no working result due to scope issues)
  APPROVED: Unified artifact list with toggle-to-identify
    - One scrollable list: all types together (trails + tracks + waypoints + routes)
    - Color-coded by type
    - Type filter pills: [ALL] [TRAILS] [TRACKS] [WAYPOINTS] [ROUTES]
    - Updates live on zoom/pan (same viewport query data)
    - Check/uncheck → instant map refresh
    - Tap item name → highlight/pulse on map
    - Optional: press coordinate → Compose dialog lists nearby items from
      viewport data, toggle on/off
    - Optional: directional arrowheads on track/trail lines
  KEY INSIGHT: Selection drives the map, not the other way around.
    The list is the interface, the map is the display.

DECISION: Trail Imports Include Trailheads
  - trail_sources.json has trailhead_asset field per source
  - Future: trail import automatically includes trailheads in same process
  - Deterministic IDs: ugrc_ + TrailheadID for dedup
  - No spatial DB schema changes

DECISION: Detail Panel Rebuild
  - Current panel has inconsistent button rendering
  - Solution: rebuild from scratch with new composable name
  - All buttons created in one pass with identical styling
  - Include: RENAME, DELETE, CHANGE TYPE, SHARE, EXPORT, ALIASES

DECISION: Track Survey on Save Panel
  - After recording stops, save panel includes:
    Difficulty: [Easy] [Moderate] [Hard] [Expert]
    Ride again? [Yes] [No]
    Share with community? [Yes] [No]
  - Local capture in V2.5, upload to hosted DB in V2.6
  - Adapt existing ride survey (ConvoyCompletedRideDetailScreen) structure

DECISION: Trail Section Numbering
  - Duplicate trail names get Windows-style suffixes
  - "Hurricane Rim Trail", "Hurricane Rim Trail (2)"
  - Display-time fix in ArtifactListPanel, no data modification
  - 85% overlap detection deferred to V2.6 hosted model
