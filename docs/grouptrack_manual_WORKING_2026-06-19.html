4. Maps, Trails & Tracks (the heart of V2.5)

The two maps and everything that feeds them. This is where V2.5’s big changes live — the Work with Artifacts panel, trail import, and the map source catalog.
Work with Artifacts — the V2.5 centerpiece.
V2.5 replaces the simple Display Panel with the Work with Artifacts panel — a single interface to toggle, select, edit, and import all four artifact types. On the Planning Map it has full editing and import functions; on the Convoy Map the same panel is display-only (editing and import are not available during live convoy operations).

Artifact types

Trails
Toggle ON to display trail overlays from the spatial database, loaded dynamically for your current viewport. Trails appear as solid cyan lines (weight 4); color varies by CartoCode classification — blue (#00AAFF) OHV/road-concurrent, orange (#FF8800) hiking & biking, yellow (#FFCC00) hiking-only, purple (#AA44FF) biking-only, cyan (#00FFFF) default. Trails display at zoom 8+; zoom in to see them.
Tracks
Toggle ON to display your recorded GPS tracks from the spatial database, loaded by viewport like trails. Tracks appear as neon green (#39FF14) dashed lines (weight 3). Tapping a track shows its name (from the GPX filename).
Waypoints
Toggle to display user-created waypoints. 10+ standard types: trailhead, fuel, gate, hazard, scenic viewpoint, water source, camp, parking, junction, rally, and others. Drop one by long-pressing the map on empty ground (not on a vehicle marker) — a type picker opens.
Routes
Toggle to display saved routes from the spatial database, the same viewport-aware way as trails and tracks. Build a route with “+ ROUTE” (see “Creating a Route”). Routes display as magenta lines. (Importing routes from GPX, and the Draw/Suggest methods, are coming in upcoming updates.)

SELECT / Edit and the three-state control

SELECT/Edit opens the artifact list for a type, scoped to the current view: a checkbox per item, Select All / Deselect All, and per-item actions. Each type also has a three-state display control — ON (show all in view), OFF (hide), and SELECTED (show only the items you checked). Each map remembers its own display selections independently: what you pick on the Convoy map no longer carries over to the Planning map.

Creating a Route (early access)

  • Open the map (Convoy or Planning) and open Work with Artifacts, then tap “+ ROUTE”. The Route+ toolbar appears.
  • Tap “New”. A “Name this route” box appears with a suggested name — accept it or type your own — then tap “Start”.
  • Tap “Add” (it turns green), then tap the map to drop each point. Each point snaps to the nearest trail or track if one is close by, so your route follows established paths; tap away from any trail to place a free point exactly where you tapped. A magenta line connects your points in order.
  • Use “Undo” to remove the most recent point. Pan and zoom freely between taps to reposition the map.
  • Tap “Save” to store the route. It is saved on your device, redraws on the map in magenta, and appears in Work with Artifacts → Routes under the name you gave it. Tap “Discard” to leave without saving.
  • To move the Route+ toolbar around the map, the panel must be expanded (accordion open). Drag the grip handle in the header to reposition; when collapsed, tapping the header expands it rather than moving it.
Routes display in magenta. Saved routes load from the spatial database the same viewport-aware way as trails and tracks. Saving a half-finished route to resume later (“In Progress”), editing a saved route’s geometry, and the Draw and Suggest methods are coming in upcoming updates.

Import Artifacts & RESYNC TRACKS

  • Open Work with Artifacts and choose Import; pick your GPX file (the picker opens your device storage). Large files are processed one track at a time, so even big exports import without crashing.
  • When it finishes, a recap shows “X new / Y already in library.” New tracks draw on the map immediately. (If the artifact list looks empty, leave the screen and return — known refresh gap; the data is saved.)
  • Duplicates are identified by shape (geometry), not name: re-importing the same file is safe and shows “0 new / N already in library.”
  • RESYNC TRACKS recovers device track files that aren’t in the database (e.g. after an update): it scans my_tracks/ and adds any track not already saved. Run it again to confirm — a second run should add 0.
  • Tracks only, this build: importing a GPX brings in its tracks; waypoints and routes inside the file are skipped for now (separate import coming). The list caps at 200 shown — larger libraries are paged in a later build.

Trail & track display

When you open the Planning Map, GroupTrack scans your my_tracks/ directory and syncs any new GPX files into the spatial database in the background (it doesn’t block the map). Files already in the database are skipped. As you pan and zoom, the track query updates automatically (400 ms debounce) so only visible tracks load — instant response even with large libraries.

The current release includes trail data for southern Utah and northern Arizona (the St. George to Grand Canyon corridor). Additional regional datasets will be downloadable in future updates through the Trail Source Manager. Trails load by viewport using bounding-box indexing; below zoom 8 they are hidden for readability.

  • Track lazy-load from the spatial database with GPX sync
  • Work with Artifacts panel — display toggles, SELECT/Edit list, import buttons
  • Per-type SELECT/Edit list (checkboxes, Select All/Deselect All)
  • Trail display: cyan solid lines, CartoCode coloring
  • Track display: neon green dashed lines from the spatial DB
  • Automatic GPX→spatial-DB track sync on launch
  • Route creation — point-to-point with snap-to-trail/track, name, save (early access)
  • Waypoint creation — long-press on the map → type picker
  • Tile download system fix; expanded tile source catalog (16 sources); API key management
  • Spatial database architecture + schema v2 migration; viewport persistence; minimum zoom 8
  • Queue management backend (hold, resume, cancel, cancel all)

In progress

  • “In Progress” route drafts — save a half-finished route to resume later
  • Route Draw and Suggest methods (Point method is live)
  • Editing a saved route’s geometry; renaming from the Routes list
  • GPX import for waypoints and routes (tracks import is live)
  • Queue panel UI wired to live data
  • Artifact detail panels (tap a trail/track for properties)
  • Waypoint / Route lazy-load from the spatial database (display)

Coming in Release 3.0 / later

  • Account, Dashboard, and Ride management (Chapters 1–3) — cloud rewrite
  • Cloud sync of local artifacts to a web account (premium)
  • iPad / iOS companion app; map heading-up rotation
  • National trail model with multi-state downloads
  • Organization services tier; database backup and recovery
