1. OPENING THE PLANNING MAP
==========================================
From the main GroupTrack screen, tap PLANNING MAP.
The map opens with satellite imagery centered on your
area. No radio connection is needed — the Planning Map
works standalone for route planning and preparation.

Your display settings are preserved between visits.
If you had Trails set to ALL and Tracks to OFF, those
settings remain when you return.

==========================================
2. HEADER BAR
==========================================
The thin bar at the top of the screen contains:

  BACK         Return to main menu
  SAT          Satellite imagery tiles
  TOPO         Topographic contour tiles
  TOPO+        Topographic with labels
  QUEUES       Open download queue panel

Tap SAT, TOPO, or TOPO+ to change the map background.
The active source shows in blue, others in gray.

If you accidentally press Back, a dialog asks
"Leave Planning Map?" to prevent losing your work.
Tap STAY to remain, or LEAVE to exit.

==========================================
3. MAP NAVIGATION
==========================================
  Pinch    — zoom in/out
  Drag     — pan the map
  Tap      — show artifact popup (if tapping near one)
  Long tap — (coming soon) create waypoint

The map loads artifact data as you move. Zoom in to see
more detail. Zoom out for an overview. Your display
selections stay locked regardless of zoom level.

==========================================
4. SEARCH
==========================================
Below the header bar is a small triangle button (the
"chevron"). This is the search toggle.

  Tap ▼ to open the search bar
  Type a location name (city, park, trail area)
  Press Enter on your keyboard
  The map flies to that location
  The search bar closes automatically
  The keyboard dismisses

Examples:
  "Zion UT" — flies to Zion National Park
  "Moab" — flies to Moab, Utah
  "Pine Valley" — flies to Pine Valley area

Tip: Add the state abbreviation for better results
(e.g. "Hurricane UT" not just "Hurricane").

==========================================
5. ARTIFACT DISPLAY
==========================================
The Planning Map displays four types of artifacts:

  TRAILS     Mapped trail paths (green lines)
  TRACKS     Your recorded GPS rides (blue dashed)
  WAYPOINTS  Point markers (colored pins)
  ROUTES     Planned paths (purple lines)

Each type can be independently turned on, off, or
filtered to show specific items.

==========================================
6. THREE-STATE DISPLAY CONTROLS
==========================================
Open the Work With Artifacts panel (bottom of screen).
Each artifact type has three buttons:

  OFF (gray when active)
    Hides all items of this type from the map.
    Tap OFF to clear the map of that type.

  ALL (blue when active)
    Shows all items of this type in the current view.
    As you zoom and pan, new items appear automatically.

  SEL/EDIT (green, blue when active)
    Opens a list of all items in the current map area.
    Check the ones you want to display. Uncheck the rest.
    Close the panel. Only your checked items display.
    Zoom and pan freely — your selection stays locked.

The active button shows in blue with white text.
Available buttons show in green.

To change state, just tap a different button.
Each button does exactly one thing — no cycling,
no confusion.

==========================================
7. SELECT/EDIT PANEL
==========================================
Tap SEL/EDIT to open the list panel for that type.

The panel shows all items in the current map area:
  ☑ JEM Trail
  ☑ Hurricane Rim Trail
  ☐ Barrel Roll Trail
  ☑ Gooseberry Mesa Loop

Controls at top:
  SELECT ALL — check everything
  DESELECT ALL — uncheck everything

Tap any item name to open its Detail Panel (see below).

When you close the panel:
  - All checked → switches to ALL (blue)
  - Some checked → switches to SEL/EDIT (blue)
  - None checked → switches to OFF (gray)

Your selection is locked. Zooming and panning do NOT
change which items are displayed.

==========================================
8. DETAIL PANEL
==========================================
Tap an item name in the Select/Edit list to open its
detail panel. Title shows "Working with [item name]".

Available actions:
  RENAME          Change the display name
  DELETE          Remove from database
  SHARE           Email as GPX attachment (coming soon)
  EXPORT          Save GPX to Downloads (coming soon)
  CHANGE TYPE     Change waypoint type (waypoints only)
  VIEW ALIASES    View alternate names (coming soon)

Each action button is color-coded:
  Blue = RENAME
  Red = DELETE
  Green = SHARE, EXPORT
  Orange = CHANGE TYPE

==========================================
9. IMPORT ARTIFACTS
==========================================
At the bottom of the Work With Artifacts panel:

  IMPORT TRAILS
    Manage trail data sources. The app comes pre-loaded
    with 5,732 UGRC trails for southern Utah.

  IMPORT ARTIFACTS
    Scans your Downloads folder for GPX and KML files.
    Tap a file to import its tracks, waypoints, and
    routes into the spatial database.

Imported artifacts appear on the map immediately.
Use RESYNC TRACKS to re-scan the track directory.

==========================================
10. DOWNLOAD PANEL
==========================================
The download panel has three collapsible sections.
Tap the section header arrow to expand or collapse.

  ▶ MAP CONTROLS (collapsed by default)
    FLYOVER — automated map tour
    DOWNLOAD ZOOM — set zoom level for tile downloads

  ▼ DOWNLOAD AREA (expanded by default)
    SELECT TYPES — check tiles, trails, or both
    DRAW AREA — tap to draw a rectangle on the map
    START DOWNLOAD — begins downloading to device
    Downloads run through the queue system

  ▶ UPLOADS (collapsed by default)
    Upload tracks, routes, waypoints to cloud
    (Coming in V2.6)

==========================================
11. DOWNLOAD QUEUE
==========================================
Tap QUEUES in the header bar to see download progress.

The queue panel shows:
  - Active downloads with progress bars
  - Pending downloads waiting to start
  - Completed downloads

When no downloads are active, the panel shows
"Download queue is empty."

==========================================
12. TIPS & TRICKS
==========================================

OVERLAPPING ARTIFACTS
  When multiple trails, tracks, or routes overlap in
  the same area, tap the overlapping spot. A popup
  appears showing ALL nearby artifact names for
  4 seconds. No need to precisely tap a single line.

MAXIMIZE MAP SPACE
  - Search bar starts collapsed — more map visible
  - Drag panels to the side when not needed
  - Collapse download panel sections you're not using

PLAN OFFLINE
  Download tiles and trails at home on WiFi. In the
  field, the map uses cached tiles automatically.
  No internet needed for map display.

PRESERVE YOUR SELECTIONS
  Your display settings survive navigation. Leave the
  Planning Map and come back — your ON/OFF/SELECTED
  states are exactly as you left them.

SEARCH TIPS
  - Add state abbreviation: "Zion UT" not "Zion"
  - Use park names: "Snow Canyon" works
  - Press Enter — no FIND button needed
  - Search bar auto-closes after search
