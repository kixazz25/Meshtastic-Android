The design

  • Top: the current state — Connected to <long name> with DISCONNECT, or Not connected — select a radio below.
  • Radios by their long name (the rider's name for the radio, e.g. "lost again — T1000-E"); the node id and the Bluetooth name small underneath. A radio never connected yet shows its Bluetooth name until its long name is known.
  • Radio actions at the bottom: Apply ride to radio · Add a radio · Forget a radio · Close.
  • On the side: the Meshtastic menu (temporary), and Settings (experienced mesh operators only).
