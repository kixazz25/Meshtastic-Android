2.6h — after 2.6g

Land ownership for all fifty states

⭐ Utah works and proved itself unattended on 09-03. The other forty-nine need their own entries.

The URL pattern is fixed — only the item id changes:
hub.arcgis.com/api/v3/datasets/{ID}/downloads/data?format=geojson&spatialRefId=4326&where=1%3D1
⚠ spatialRefId=4326 is load-bearing: Utah's layer is named "WM" and arrives in web mercator without it.

⭐ Most state catalogues are ArcGIS Open Data, so the same endpoint works and this is a LOOKUP exercise rather than an integration. ⚠ But not all: Nevada's SMA layer is on a BLM hub, Colorado's is shapefile/KMZ/web service, and Arizona's trust land sits behind a parcel viewer with no direct download.

⛔⛔ THE REAL WORK IS WHAT THE POLYGONS MEAN, NOT THE URL. Utah maps ownership CONTINUOUSLY, so "not inside a private polygon" means public. ⚠ A layer that lists PUBLIC land positively inverts that: absence would mean private or unmapped, and marking every unmapped trail private hides it under the shipped default — which looks exactly like missing data.

So each catalogue entry needs three things: the item id · which field carries ownership · whether the layer is continuous or positive.

⭐ PUBLIC MEANS STATE AND FEDERAL (Fred, 09-03), which is why a single national BLM layer will not do — it would miss state trust land, state parks and state forests, and that is the ground riders use.
