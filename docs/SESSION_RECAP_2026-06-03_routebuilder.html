5. Working method (for continuity)

Rapid prototyping: explode rough feature items into executable detail BEFORE building; catch bad design/state/use-case cheaply at design time, not via post-build refactor (proven by the interim-JSON / draft-storage decision). Detail deepens only to firmness of intent × use case × knowledge; where firm, build; where moving, scaffold-and-defer. Documentation of current rules + current code (xrefs) + current functionality (this recap / checklist) IS the input to impact assessment, which enables expansion without breaking. Live-read-before-every-patch; string-anchored guarded patches (abort, no partial writes); per-file CRLF/LF preserved.
