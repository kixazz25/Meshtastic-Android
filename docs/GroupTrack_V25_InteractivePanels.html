INTERACTIVE PANEL REFERENCE

Click buttons and panels to navigate the app structure. All menus and functions are accessible from the base screens.


CONVOY MAP FUNCTIONS

GROUP button -- Group HUD with unit counts, span, lead/tail

MY CART button -- Personal cart stats (speed, heading, battery, altitude)

SELECT CART button -- Opens cart picker, selects any cart for NodeDetailHud (COMPLETED)

HIDE button -- Collapse HUD to minimal pill

GEAR button -- Settings menu (radio config, convoy settings, Work with Queues, Spatial Data, Import)

DISPLAY panel -- Toggle track/trail/waypoint/route visibility + Change Map Source


PLANNING MAP FUNCTIONS

MAP BAR -- SAT/TOPO/TOPO+ (fixed titles, any source per title) + SEARCH

DISPLAY panel -- Same as convoy + Change Map Source

DOWNLOAD FAB -- Download panel (tiles, trails, route tools, V2.6 spatial downloads)

SPATIAL DATA FAB -- Work with Spatial Data (tracks, routes, waypoints with type filters)

IMPORT FAB -- Import external data (trails from agencies, GPX/KML files)

+ WPT button -- Waypoint creation (represents long-press on map)

Q:3 button -- Work with Queues (3 queues with drill-down)

LEGEND BAR -- Generated from spatial data types on map


V2.5 / V2.6 / V3.0 INDICATORS

[V2.6] = Stub only. Processing activated in V2.6.

[V3.0] = Future capability.
