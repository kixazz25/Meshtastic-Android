Version 2.5 Release Notes — What’s New
Field Test Release  ·  Map Feature Update  ·  updated 2026-06-02

About this release

V2.5 completes the free map product: trail and trailhead data you can download straight onto your maps, plus a single, consistent way to show and hide Trails, Tracks, Waypoints, and Routes on both the Convoy Map and the Planning Map. This is a FIELD TEST build — known rough edges are listed at the end.

New in this build (2026-06-02): Track import fixed for large files

  • Big GPX files import without crashing. Large onX “markups” exports (25MB+, dozens of tracks) used to crash the app during import — that’s fixed. You can import your full track collection in one pass.
  • Much faster. Large tracks that took minutes each now take seconds.
  • Import summary. After an import you see “X new / Y already in library” — how many tracks were actually added versus already on your device.
  • Safe to re-import. Tracks already saved are recognized by their shape and skipped — re-importing the same file does not create duplicates.
  • Limitation this build: importing a GPX brings in its tracks only. Any waypoints or routes in the file are skipped for now (a separate import feature is coming). Dropping waypoints on the map yourself still works.

Headline: Import Utah Trails onto your map

The trail source catalog lets you pull a full set of Utah trails and trailhead waypoints directly onto your maps as artifacts — no files to copy, and no internet needed once they’re down.

How to import UGRC Utah Trails:

  1. Open Work with Artifacts (accordion button).
  2. Select Import Trails. The trail source list displays.
  3. Select UGRC Utah Trails.
  4. Tap Validate/Confirm. Trails and trailhead waypoints download as artifacts.
  5. Fully close the app, force close, then reopen. Imported trails and trailheads now appear.

If imported trails don’t show: (1) Fully close and reopen (or Force Stop) so trail data loads. (2) Zoom in — about 49,000 trails only draw at close zoom (see Known Issues).

What else is new

  • Trail source catalog — browse and import. UGRC Utah Trails first (~49,000 trails + 591 trailheads). BLM/USFS planned.
  • One consistent artifact display — Trails/Tracks/Waypoints/Routes show and hide the same way on both maps.
  • Independent map selections — the Convoy and Planning maps each keep their own selections, saved across restarts.
  • SELECTED shows exactly what you pick — draws only the items you checked, consistent on both maps.
  • Drop waypoints on the map — long-press empty ground for a 12-type picker plus an optional name. (Works on the Planning Map; Convoy Map waypoint drop is in progress — see Known Issues.)
  • Work with Artifacts panel — accordion; per-type OFF / ON / SELECTED plus an item list.
  • Default on launch — Trails ON, others OFF.
  • RESYNC TRACKS — rebuilds the track list from your saved GPX files, and adds any track on the device that isn’t yet in the database.
  • Zoom readout — the compass shows the zoom level (N · Z##).
  • Standalone GPS / offline maps — carried from V2.4.

Requirements

Android 8.0+ (tablet recommended). Auto-update via the Play Store internal track. 500MB+ free for tiles (trail data ~15–30MB per state). Meshtastic SenseCAP T1000-E or LoRa firmware 2.6+ (for convoy only, not maps). Internet needed once to import/download.

Known issues — please read

  • Trails not visible zoomed far out — expected; zoom in.
  • Item list sometimes shows no names — known; being addressed.
  • Item list shows up to 200 entries — paging is coming in a later build.
  • After a track import, the artifact list may not refresh until you leave the screen and return. (Tracks appear on the map right away.)
  • Convoy Map: QUEUES button and waypoint long-press are not working yet — both work on the Planning Map; convoy parity is in progress.
  • Tracks missing after an update — RESYNC TRACKS rebuilds.

Resolved since last build

  • Track re-import no longer duplicates. The earlier “don’t import the same tracks repeatedly” warning is fixed for tracks — they’re de-duplicated by shape, so re-importing skips ones already present. (Trail-source re-import dedupe is still rolling out — import UGRC once.)
  • Large track files no longer crash the import.
  • Map selections are independent per map and saved.

Troubleshooting

  • Imported trails don’t appear → zoom in; confirm the import finished.
  • Imported tracks don’t appear in the list → leave the screen and return; they’re already on the map.
  • A big track file used to crash → fixed in this build; if any import still stalls, note the file size and track count and report it.
  • No vehicles (convoy) → is the radio connected (green)? Same channel and PSK?
  • Tiles blank offline → download tiles while online first.
  • Tiles not loading online → check your internet.
  • A track is missing → RESYNC TRACKS.
  • Anything else → report it (note what you tapped and what you expected).
