RELNOTES-2026-08-21

V2.6g — Home State Import Pipeline

Release date: In development · Branch: feature/convoy-event-ride

Import Trails — by State or by Area (New)

NEW Import Trails now asks how you want to choose your ground. One button on the Map Features panel, two ways in:

  • By State — pick any state from the list. Every available source for that state is processed. Use this when you're planning a trip somewhere new.
  • By Area — draw a box on the map. GroupTrack works out which states your box reaches and processes every source that covers it. Your box can cross state lines — a ride that runs from Utah into Arizona brings in both.

Either way there is no source checklist. Every source that covers your ground runs, because that is what lets one source fill in what another is missing.

Import Progress Detail

NEW Every import now records what happened to each record, not just how many were added. Per source: how many were read, how many fell inside your state or area, how many you already had, how many were added, and how many could not be processed.

The summary still shows one number — records added. The detail sits behind the source name if you want it, and it is written into the import record on your device either way, so it can be looked up later.

CHANGE Each import run now carries an identifier, so a run can be identified exactly when something needs looking into.

Known Issues — added 2026-08-21

  • Some sources report errors on every record. US Geological Survey National Trails is affected in every area tested; other sources are affected in some areas and not others. Under investigation. These sources previously reported zero records with no indication anything had gone wrong — the new counts are what made it visible.
  • A state may be listed for your area without having trails in it. States are matched using a rectangle around each state and those rectangles overlap, so a neighbouring state can be included and then contribute nothing. It costs download time; it does not affect your data. A way to skip those states is coming.
  • The per-source detail does not open on the completion screen yet. The figures are recorded correctly; only the on-screen expansion is affected.
  • Re-importing the same state on the same day replaces that day's earlier import record.

Home State Setup (New)

NEW One-tap trail data setup on first launch. When GroupTrack detects no trail data, it offers to load your home state's trails automatically:

  • GPS auto-detection suggests your state (uses Android Geocoder for accuracy at state borders)
  • Searchable state picker with all 50 US states + DC + PR + USVI
  • California split into North (San Luis Obispo area and north) and South (Santa Barbara/Bakersfield area and south)
  • All available data sources processed automatically — US Forest Service, US Geological Survey, National Park Service, state agencies, and Open Source Maps (Geofabrik OSM)
  • Progress display: per-source step indicators (✅/►/○), download progress in MB, running elapsed clock
  • Blinking "Do not close GroupTrack" banner during processing
  • Completion summary with per-source record counts and grand total
  • New Hampshire verified: 42,338 OSM trails + 1,010 catalog trails imported in ~4 minutes

Geofabrik State Asset

NEW Shipped geofabrik_states.json — 54 entries with download URLs for every US state and territory. Supports the automatic Geofabrik GPKG download (302 redirect handling included). Refreshable via update_geofabrik_states.py.

Release-Assets Folder

NEW release-assets/ folder in the repo. Holds dated docs (manual, release notes, quickstart) and two Python scripts. One command (python release-assets/prepare_release_assets.py) refreshes Geofabrik URLs, copies newest dated docs to app assets, and verifies markers.
