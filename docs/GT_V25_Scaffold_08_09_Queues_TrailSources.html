TRAIL SOURCE RULES

  • Table: trail_sources (extension db). Vetted/approved catalog.
  • Two import methods: full source OR area-based with suggested sources.
  • Both methods validate before import: URL reachable, format valid, no active import.
  • Import → TrailImporter: parse → dedup (source_unique_id) → insert/alias → log → tile LOW
  • Dedup match = add alias. New = full chain.
  • Area import filters downloaded data to drawn boundary only.
  • Area selector is transient — not saved.
  • source_ingestions tracks import history per source.
