CONVOY MAP PROCESS RULES

  • DISPLAY only for artifacts. No EDIT. No IMPORT.
  • Click artifact → detail + aliases (read-only)
  • Long-press → waypoint creation (same flow as Planning)
  • Map source change via GEAR > Settings > Map Sources

ALIAS RULES — CONVOY MAP

  • View aliases: YES | Add: NO | Set preferred: NO | Delete: NO

DATABASE

  • Reads: grouptrack_spatial.db (trails, tracks, waypoints, routes)
  • Display name: COALESCE(preferred_alias, spatial.name, agency_id, 'Unnamed')
  • Query bounded by map viewport for performance

PLANNING MAP PROCESS RULES

  • Full artifact management: DISPLAY + EDIT + IMPORT
  • Click artifact → detail + aliases + actions
  • Long-press → waypoint creation with proximity + alias
  • + WPT FAB → same as long-press
  • + RTE FAB → route creation (draw/snap/convert)

ALIAS RULES — PLANNING MAP

  • View: YES | Add: YES | Set preferred: YES | Delete user: YES | Delete agency/aws: NO

DATABASE

  • Reads: both databases. Spatial for geometry, extension for properties+aliases.
  • Writes: all creation flows write to both databases via lifecycle owners.
