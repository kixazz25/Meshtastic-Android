# GroupTrack — Version 2.5 Release Notes (What's New)
_Field Test Release · Map Feature Update · updated 2026-06-02_

> NOTE: This supersedes v2.5_release_notes.md (dated 2026-05-31). Connector is create-only so this is a new dated file; ALL prior content is carried forward, with the 06-02 track-import changes folded in and the now-resolved track-dupe known-issue corrected. (Working Agreement rules 4b + 5.)

## About this release
V2.5 completes the free map product: trail and trailhead data you can download straight onto your maps, plus a single, consistent way to show and hide Trails, Tracks, Waypoints, and Routes on both the Convoy Map and the Planning Map. FIELD TEST build — known rough edges listed at the end.

## Headline: Import Utah Trails Onto Your Map
The big addition is the trail source catalog — pull a full set of Utah trails + trailhead waypoints directly onto your maps as artifacts, no files to copy, no internet needed once down.

**How to import UGRC Utah Trails:**
1. Open Work with Artifacts (accordion button).
2. Select Import Trails. The trail source list displays.
3. Select UGRC Utah Trails.
4. Tap Validate/Confirm. Trails + trailhead waypoints download as artifacts.
5. Fully close the app, force close, reopen. Imported trails/trailheads now appear.

**If imported trails don't show:** (1) Fully close/reopen (or Force Stop) so trail data loads. (2) Zoom in — ~49,000 trails only draw at close zoom. Intentional (see Known Issues).

## NEW in this build (2026-06-02): Track import is fixed for large files
- **Big GPX files import without crashing.** Large onX "markups" exports (25MB+, dozens of tracks) used to crash the app during import — fixed. You can import your full track collection in one pass.
- **Much faster.** Large tracks that took minutes each now take seconds.
- **Import summary.** After an import you see "**X new / Y already in library**" — how many tracks were actually added vs. already on your device.
- **Safe to re-import.** Tracks already in your library are recognized by their shape and skipped — re-importing the same file does not create duplicates.
- **Limitation this build:** importing a GPX brings in its TRACKS only. Any waypoints or routes in the file are skipped for now (separate feature, coming). Dropping waypoints on the map yourself still works.

## What Else Is New
- **Trail source catalog** — browse + import. UGRC Utah Trails first (~49,000 trails + 591 trailheads). BLM/USFS planned.
- **One consistent artifact display** — Trails/Tracks/Waypoints/Routes show + hide the same way on both maps via one shared process.
- **Independent map selections (NEW)** — Convoy and Planning maps each keep their OWN selections, saved across restarts. No longer carries between maps.
- **SELECTED shows exactly what you pick (NEW)** — SELECTED draws only checked items, consistent on both maps.
- **Drop waypoints on the map (NEW)** — long-press empty ground → 12 types (hazard, gate, water, fuel, shelter, trailhead, viewpoint, campsite, parking, junction, rally, other) + optional name. Appears on both maps. (NOTE: works on the Planning Map; Convoy Map waypoint drop is in progress — see Known Issues.)
- **Work with Artifacts panel** — accordion; per-type ON/OFF/SELECTED + item list.
- **Default on launch** — Trails ON, others OFF.
- **RESYNC TRACKS** — rebuilds the track list from saved GPX files, and adds any track on the device that isn't yet in the database.
- **Zoom readout** — compass shows zoom level (N · Z##).
- **Standalone GPS / offline maps** — carried from V2.4.

## Requirements
- Android 8.0+ (tablet recommended). Auto-update via Play Store internal track. 500MB+ free for tiles (trail data ~15–30MB/state). Meshtastic SenseCAP T1000-E or LoRa fw 2.6+ (only for convoy, not maps). Internet needed once to import/download.

## Known Issues — Please Read
- **Trails not visible zoomed far out** — expected; zoom in. Clean cutoff being finalized.
- **Item list sometimes shows no names** — known; being addressed.
- **Item list shows up to 200 entries** — larger lists are being paged in a later build.
- **After a track import, the artifact list may not refresh** until you leave the screen and return. (Tracks appear on the map right away.)
- **Convoy Map: QUEUES button and waypoint long-press not working yet** — both work on the Planning Map; convoy parity is in progress.
- **Tracks missing after update** — RESYNC TRACKS rebuilds.

**Resolved since last build:**
- **Track re-import no longer duplicates.** The earlier warning "don't import the same tracks repeatedly — re-import can add duplicates" is FIXED for tracks: tracks are de-duplicated by shape, so re-importing skips ones already present. (Trail-source re-import dedupe still rolling out — import UGRC once.)
- **Large track files no longer crash the import.**
- Map selections are independent per map and saved (the earlier "selections carry between maps" behavior is fixed).

## Troubleshooting
- Imported trails don't appear → zoom in; confirm import finished.
- Imported tracks don't appear in the list → leave the screen and return (known refresh gap); they're already on the map.
- Big track file used to crash → fixed in this build; if any import still stalls, note the file size + track count and report it.
- No vehicles (convoy) → radio connected (green)? same channel + PSK?
- Tiles blank offline → download tiles while online first.
- Tiles not loading online → check internet.
- Track missing → RESYNC TRACKS.
- Anything else → report it (note what you tapped + expected).
