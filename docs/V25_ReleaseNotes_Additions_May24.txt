GroupTrack V2.5 — Release Notes Additions
Updated: May 24, 2026
=========================================

NEW FEATURES COMPLETED TODAY:
(Add to existing V2.5 Release Notes)

Waypoint Spatial Display
------------------------
User waypoints are now stored in the on-device spatial database
and displayed as colored circle markers based on waypoint type.
Ten standard types supported: trailhead, fuel, gate, hazard,
scenic viewpoint, water source, camp, parking, rally point, other.
Each type has a distinct color for at-a-glance identification.

Manual Reference: Chapter 6 (Work With Artifacts)

Route Spatial Display
---------------------
Planned routes are stored in the on-device spatial database and
displayed as gold dot-dash lines, visually distinct from trails
(solid colored) and tracks (green dashed). Routes use the same
viewport-aware lazy loading as trails and tracks.

Manual Reference: Chapter 6 (Work With Artifacts)

Expanded GPX Import
-------------------
The IMPORT ARTIFACTS function now processes all three GPX element
types from a single file: tracks (<trk>), waypoints (<wpt>), and
routes (<rte>). A single GPX file containing all three types is
imported in one operation. After import, a summary shows counts
per type: "Imported: 3 tracks, 5 waypoints, 1 route." Source files
are automatically removed from Downloads after successful import.

Waypoint types are automatically mapped from GPX <type> elements
to GroupTrack's 10 standard types.

Manual Reference: Chapter 6 (Work With Artifacts), Chapter 11
