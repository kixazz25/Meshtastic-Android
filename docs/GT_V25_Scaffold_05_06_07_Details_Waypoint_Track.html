DETAIL PANEL PATTERN (same composable, 4 type configs)

  • Badge + display_name + aliases + type-specific properties + actions
  • Alias source tags: agency (trail import), user (manual), aws (V2.6 standardization)
  • Star = preferred. One per artifact. LOCAL ONLY (is_preferred not sent to AWS).
  • Min 1 alias always. Agency/AWS undeletable. User deletable unless only one.

DELETE RULES

  • TRAIL: no delete (agency data, batch remove by source only)
  • TRACK: warn if route.source_track_id references it
  • WAYPOINT: BLOCK if route.trailhead_id references it
  • ROUTE: BLOCK if route_properties.ride_id not null
  • All deletes cascade: properties + aliases + survey(track) + queue entries + data_log

WAYPOINT CREATION LIFECYCLE (Owner: WaypointManager)

  1. Long-press → type select → proximity check via proximity_config (100m default)
  2. IF NEARBY: show existing + aliases → (A) add alias, (B) set preferred, (C) create new
  3. IF (A): AliasManager adds alias. No new spatial. Done.
  4. IF (C) or NO NEARBY: name → insert waypoints (spatial, POINT WKT) → insert waypoint_properties → AliasManager first alias → AuditLogger data_log → share? → QueueManager upload_queue

DATABASE WRITES

  1. grouptrack_spatial.db: INSERT INTO waypoints (waypoint_id, name, type, geometry, created_at, updated_at)
  2. grouptrack_data.db: INSERT INTO waypoint_properties, artifact_aliases, data_log
  3. geometry = SpatialDbManager.pointWkt(lat, lng)

PROXIMITY CONFIG (soft-coded, adjustable)

  • waypoint: 100m | trail: 80% overlap | track: 70% overlap | route: 85% overlap

TRACK CREATION LIFECYCLE (Owner: TrackManager)

  1. GPS stops or file imported → name prompt → Save/Skip
  2. Save GPX/KML to my_tracks/ → insert tracks (bbox = bboxWkt from points)
  3. Insert track_properties (distance, duration, speed, elevation)
  4. AliasManager: first alias (preferred, source='user')
  5. Share Y/N → if Y: shared=1, upload_queue entry
  6. Survey → insert track_surveys (enjoyment 1-5, ride again Y/N)
  7. AuditLogger: data_log entry
  8. TileRequestTrigger: tile_queue HIGH priority

V2.6 POST-UPLOAD

  • AWS returns area track aliases → user picks standard or keeps own
  • Three options: ACCEPT STANDARD | KEEP MINE REMOVE AWS | KEEP MINE KEEP AWS
