GroupTrack V2.5 — Release Notes Additions
Updated: May 25, 2026
=========================================

ADD TO EXISTING V2.5 RELEASE NOTES:

Import Artifacts Panel
----------------------
The IMPORT ARTIFACTS button in Work With Artifacts opens a panel
showing all GPX and KML files in your Downloads folder. Tap any
file to import. The parser automatically extracts tracks, waypoints,
and routes from a single GPX file. After import, a summary shows
counts per type: "Imported: 3 tracks, 5 waypoints, 2 routes."
Source files are automatically removed from Downloads after
successful import.

Manual Reference: Chapter 6 (Work With Artifacts), Chapter 11

Resync Tracks
-------------
The RESYNC TRACKS TO SPATIAL DB button in the import panel
rebuilds the spatial database index from GPX files in my_tracks/.
Use this after manually adding or removing track files, or as a
recovery tool if the spatial database and track files get out of
sync.

Manual Reference: Chapter 6 (Work With Artifacts)

Waypoint Spatial Display
------------------------
User waypoints are stored in the on-device spatial database and
displayed as colored circle markers based on waypoint type. Ten
standard types: trailhead, fuel, gate, hazard, scenic viewpoint,
water source, camp, parking, rally point, other. Each type has a
distinct color and letter symbol for identification while riding.

Manual Reference: Chapter 6 (Work With Artifacts)

Route Spatial Display
---------------------
Planned routes are stored in the on-device spatial database and
displayed as gold dot-dash lines, visually distinct from trails
(solid colored) and tracks (green dashed). Routes use viewport-
aware lazy loading for instant pan/zoom response.

Manual Reference: Chapter 6 (Work With Artifacts)

Expanded GPX Import
-------------------
GPX files can contain any combination of tracks (<trk>), waypoints
(<wpt>), and routes (<rte>). All three types are imported in one
operation. Waypoint types are automatically mapped from GPX <type>
elements to GroupTrack's 10 standard types.

Manual Reference: Chapter 11 (Trail Import Guide)

Zoom Level Display
------------------
The current map zoom level and maximum offline tile zoom are shown
next to the north indicator on both Planning Map and Convoy Map.
Format: N · Z14 · offline Z18. This helps identify tile coverage
while riding.

Manual Reference: Chapter 9A (Trail Display)

Legend Bar Update
-----------------
The Planning Map legend bar now shows all artifact types with
correct colors: OHV Trail (blue), Hike+Bike (orange), Hike
(yellow), Bike (purple), Trail (cyan), Track (green), Route
(gold), Waypoint (green).

Manual Reference: Chapter 6 (Work With Artifacts)

UI Changes — Planning Map
--------------------------
The TRACKS button and Display Panel have been removed from the
Planning Map header. All artifact display, import, and management
functions are now consolidated in the Work With Artifacts panel.

- Track display toggle: Work With Artifacts → Tracks switch
- Trail display toggle: Work With Artifacts → Trails switch
- Waypoint display toggle: Work With Artifacts → Waypoints switch
- Route display toggle: Work With Artifacts → Routes switch
- Track import: Work With Artifacts → IMPORT ARTIFACTS
- Trail import: Work With Artifacts → IMPORT TRAILS
- Downloaded areas: moved to download management (future update)

The QUEUES button remains on the Planning Map header for download
queue management.

Manual Reference: Chapter 6 (Work With Artifacts)

ArtifactListPanel — Select/Edit
--------------------------------
The SELECT button in Work With Artifacts opens a list panel
showing all artifacts of the selected type. Each artifact has a
checkbox for individual display control and a clickable name
that opens a detail panel with type-specific maintenance functions.

Functions available per type:
  Tracks:    Rename, Delete, Aliases (placeholder)
  Waypoints: Rename, Delete, Change Type (10 types), Aliases
  Routes:    Rename, Delete, Aliases (placeholder)
  Trails:    Aliases only (read-only, placeholder)

Select All / Deselect All provide bulk display control.

Manual Reference: Chapter 6 (Work With Artifacts)

Download Queue Panel
--------------------
The QUEUES button on the Planning Map header opens a floating
overlay showing the live download queue from DownloadQueueManager.
Active, queued, and completed downloads are shown with cancel
controls. When the queue is empty, a "No downloads in queue"
message is displayed.

Manual Reference: Chapter 7 (Downloads)
