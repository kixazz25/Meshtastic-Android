2026-08-27 — comparing the routes the app suggests

When the planner finds you rides, you can now see them side by side. Ask for routes and the app draws every one it found, each in its own colour, with a table underneath that lines them up against each other.

What you will see

  • Every route on the map at once, in its own colour.
  • A table where the rows are places and trails and each column is one route. A green check means that route reaches that feature; a number means how many miles of that trail it uses.
  • The most-used trails at the top. The trails near the top are what these rides are made of; the ones lower down are what makes them different. Two routes with big numbers on the same few trails are variations on the same ride.
  • Tap a route's name to take its line off the map so you can see the others. Tap again to bring it back.
  • Tick the ones you want to keep, type a name for the area, and they are saved — Panguitch Mi. 79 Pts. 7. The ones you did not tick are discarded.

While you are comparing

Trails, tracks and waypoints are hidden so the routes are readable, and put back exactly as you had them when you leave. The map does not switch to route-drawing mode, so tapping a route to look at it will not add points to it.

Leaving without saving keeps everything — the routes are still there next time you tap Route+. Only Save Selected finishes the job. If you tick nothing, the app asks first: all the routes go, and you would have to start the search over.

Also fixed

  • The In-Progress list no longer opens empty — with nothing to continue, Route+ simply starts a new route.
  • Renaming an in-progress route has been removed. The name you give a route when you save it is the one that matters.
  • Saved routes follow the trail correctly even when part of the route is off the edge of the screen.

What changed in this release

Which document you want

QuickStart is for a new rider on a first install — getting the app on the phone, permissions, radio pairing, and getting trails onto the map. It is a summary of how things work right now, not a history. It opens by itself the first time you install.

These release notes are for riders who already have GroupTrack. They cover what is new in this release and how to use it, and they open after an update. Earlier releases are kept below under Release history.

The user manual is the walkthrough. Where something new needs more than a paragraph, these notes point at the manual page for it.

Route planning is being rebuilt — not ready to use yet

What this means to you. Nothing in this build, and that is deliberate. The part of GroupTrack that suggests rides was taken apart and rebuilt this week. It now works properly on the bench — it will offer you several genuinely different rides from where you park, rather than one — but the screens you would use it through are still being finished.

How to use it. You cannot yet. It is listed here so you know it is coming and that the quiet in this area is work, not neglect. Manual: Planning a ride — link pending anchors

Files other riders send you now import completely

What this means to you. When someone emails you a GPX file and you tap it, everything in it comes across — the tracks, the waypoints and the routes. Before, only the tracks arrived and the rest were dropped without saying so, which is why a file could look like it imported nothing. If you learned to save files to Downloads first as a workaround, you no longer need to.

How to use it. Tap the attachment in your email and choose GroupTrack. Importing from Map Features → IMPORT TRACKS, WAYPOINTS & ROUTES still works and gives the same result. Manual: Importing files — link pending anchors

Your trails stay put

What this means to you. If you loaded your state and found the trails gone again a day or two later, that is fixed. It was a one-time cleanup that kept running every time the app opened instead of once. You should not have to load a state twice.

How to use it. Nothing to do. If your trails are missing right now, import your state one more time and it will stay. Manual: Loading trails for your state — link pending anchors

Route planning — not ready yet

What this means to you. Nothing yet. Work is going on behind the scenes to let GroupTrack suggest rides from your trail data, and to let you mark places a ride has to reach. It is not finished and is not something to rely on in this build. It is listed here so you know it is coming, not so you can try it.

Known issues as of 26 August 2026

KNOWN A state import can stop partway. Some sources finish and the rest never start. Your trail count still looks reasonable, so nothing appears wrong — but the largest source, Open Source Maps, is usually the one that did not run, and it carries most of the trail network.

What it looks like: route building offers one route where you would expect several, or comes back well short of the distance you asked for. The map still shows plenty of trails, which is what makes it confusing.
What to do: run the state import again. Trails already on your device are skipped, so only what is missing is fetched and nothing is duplicated.

KNOWN Route planning near a town suggests roads. The trail data GroupTrack imports contains roads as well as trails, and it cannot yet tell them apart. Planning from a staging point inside a town will offer you rides that follow streets.

What to do: plan from where the trails actually start — a trailhead or a parking area out of town. Work to separate roads from trails in the imported data is underway.

KNOWN An import record can be opened by the wrong import routine. The record left behind by a run is picked up by an older code path than the one that wrote it, so a run can be misread afterwards — and a stopped import may be reported inaccurately. Being fixed by pointing the existing routine at the current one rather than leaving two.

KNOWN Some trail sources report errors on every record in some areas. Affected in some areas and not others; under investigation. The per-source counts on the completion screen are what make it visible.

KNOWN A state may be listed for your area without having trails in it. States are matched using a rectangle around each state and those rectangles overlap. It costs download time; it does not affect your data.

KNOWN Re-importing the same state on the same day replaces that day's earlier import record.

V2.6g — 23 August 2026 — Home State Import Pipeline

Release date: In development · Branch: feature/convoy-event-ride

Importing routes and waypoints from a GPX file

FIX GPX files containing routes or waypoints now import. Previously only the tracks in a file were read — routes and waypoints were skipped without any message, so a file that contained them appeared to import nothing.

This affects files shared between riders, and exports from other apps.

HOW TO IMPORT

Save the file to your Downloads folder first, then open Map Features on the Ride Planning Map and choose IMPORT TRACKS, WAYPOINTS & ROUTES.

Tapping a GPX attachment directly in your email will not import routes yet — it still reads tracks only. Save it to Downloads and import it from Map Features instead. This is being worked on.

Note: the file is removed from Downloads once it has been imported.

Trail sources

FIX US Geological Survey National Trails now imports. Every record from this source was failing, in every state, and the source appeared simply to have no data for your area. It was reading the wrong field names from the service. In New Hampshire it now brings in 390 trails where it previously brought none.

Import Trails — by State or by Area (New)

NEW Import Trails now asks how you want to choose your ground. One button on the Map Features panel, two ways in:

  • By State — pick any state from the list. Every available source for that state is processed. Use this when you're planning a trip somewhere new.
  • By Area — draw a box on the map. GroupTrack works out which states your box reaches and processes every source that covers it. Your box can cross state lines — a ride that runs from Utah into Arizona brings in both.

Either way there is no source checklist. Every source that covers your ground runs, because that is what lets one source fill in what another is missing.

Import Progress Detail

NEW Every import now records what happened to each record, not just how many were added. Per source: how many were read, how many fell inside your state or area, how many you already had, how many were added, and how many could not be processed.

The summary still shows one number — records added. The detail sits behind the source name if you want it, and it is written into the import record on your device either way, so it can be looked up later.

CHANGE Each import run now carries an identifier, so a run can be identified exactly when something needs looking into.

Known Issues

  • Some sources report errors on every record in some areas. US Geological Survey National Trails is fixed (see above). Other sources are still affected in some areas and not others — under investigation. These sources previously reported zero records with no indication anything had gone wrong; the new counts are what made it visible.
  • A state may be listed for your area without having trails in it. States are matched using a rectangle around each state and those rectangles overlap, so a neighbouring state can be included and then contribute nothing. It costs download time; it does not affect your data. A way to skip those states is coming.
  • Re-importing the same state on the same day replaces that day's earlier import record.

Home State Setup (New)

NEW One-tap trail data setup on first launch. When GroupTrack detects no trail data, it offers to load your home state's trails automatically:

  • GPS auto-detection suggests your state (uses Android Geocoder for accuracy at state borders)
  • Searchable state picker with all 50 US states + DC + PR + USVI
  • California split into North (San Luis Obispo area and north) and South (Santa Barbara/Bakersfield area and south)
  • All available data sources processed automatically — US Forest Service, US Geological Survey, National Park Service, state agencies, and Open Source Maps (Geofabrik OSM)
  • Progress display: per-source step indicators (✅/►/○), download progress in MB, running elapsed clock
  • Blinking "Do not close GroupTrack" banner during processing
  • Completion summary with per-source record counts and grand total
  • New Hampshire verified: 42,338 OSM trails + 1,010 catalog trails imported in ~4 minutes
