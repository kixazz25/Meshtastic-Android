WORK WITH ARTIFACTS DESIGN (from session discussion)
=====================================================

Grid: 4 rows × 3 columns
  Rows: Tracks, Trails, Waypoints, Routes
  Columns: Display, Select/Edit, Import

DISPLAY TOGGLE (Column 1):
  - ON/OFF per artifact type
  - Lazy load shows what's in viewport
  - Goes OFF if Deselect All in Select column

SELECT/EDIT (Column 2):
  - Opens overlay on map (takes real estate)
  - Lists artifacts of that type in current map bbox
  - Checkbox per item controls map visibility
  - Select All / Deselect All
  - Fit All (zoom to show all of that type)
  - Search by name or date
  - Click item title → popup menu: Share, Rename, Fix Date, etc.
  - Changes not visible until overlay closed (return to map)
  - Toggle linked to selection: 1+ selected = ON, all deselected = OFF
  - To show single item: Deselect All → select that one

IMPORT (Column 3):
  - Trails: from trail sources (Method A, already built)
  - Tracks/Waypoints/Routes: list files from downloads dir by extension
  - Click file to import
  - Refresh map on return after import
  - Prompt to remove source file after import (Y/N)
  - Pattern: existing Work with Tracks function
