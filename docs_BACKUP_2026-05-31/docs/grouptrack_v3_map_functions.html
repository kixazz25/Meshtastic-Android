01 Map Architecture
V3.0 separates map functionality into two distinct maps. The Convoy Map remains operational and focused. The Planning Map is a new greenfield screen in the Maps section of the bottom nav.
MapPurposeFunctions
CONVOY MAP Operational — launched from main nav during a ride Live node tracking, HUD, track recording, layer switch, NET/LOCAL toggle, show downloaded areas, KML/GPX overlay (read-only, from library)
PLANNING MAP Planning — dedicated Maps section in bottom nav Waypoint creation, track/route overlays, area search, tile download management, layer preferences, storage management, AWS coverage display, route planner, download region draw
Rule: Planning Map functions never bleed into Convoy Map. During a ride the screen stays clean and operationally focused. All asset management lives in the Maps section.

02 Asset Types
⬛ TRACK
Recorded path — already ridden. GPX or KML. Solid line display. Color from assigned palette or default #6B4EFF.
-- ROUTE
Planned path — not yet ridden. GPX or KML. Dashed line display. Orange #F5A623. Types: LOOP, OUT & BACK, POINT TO POINT.
⊙ TRAILHEAD
Named meeting/start point. Waypoint subtype with icon_type=TRAILHEAD. Always visible on map regardless of toggle state.
⬡ WAYPOINT
Single named point. Types: HAZARD, LANDMARK, MEETING POINT. Standard pins, OFF by default in layer panel.
03 Track Storage Rules
FolderContents
mytracks/recorded/GPS recordings from GroupTrack
mytracks/imported/Files brought in via file picker from Downloads
mytracks/rides/{ride_id}/Auto-created when track associated with a ride. Copy of track — original in imported/ remains.
Hard rule: All tracks stored in mytracks/ folder or subfolders — no exceptions. File picker scans Downloads only, GPX and KML files only. Import copies file — original remains in Downloads.

06 Viewport-Driven Display
Hard rule: Only assets whose geometry intersects the current map viewport are shown — no exceptions. List and map display are always in sync. No asset appears in the list that is not visible in the current viewport.

08 Bounding Box Auto-Calculation

Rule: 1 mile buffer on each edge is the recommended default. Organizer can adjust the suggested bounding box before confirming download. Buffer measured from outermost track/route points.
09 Ride Creation — Hard Gate
A ride CANNOT be saved without a map boundary. SAVE button is disabled and shows "MAP AREA REQUIRED" until a bounding area exists.

10 Download Layer Preferences
User selects which layers to download. No preferences are mandated — user decides. Default recommendation: HYB only.
LayerDefaultStorage (relative)Notes
SATOFFBaseline (1×)Satellite imagery only — no labels
HYBON~1× (same as SAT)Recommended — satellite + trail/road labels
TOPOOFF~0.6×Terrain contours — useful for elevation planning
RDOFF~0.3×Lightest layer — road/POI only
SAT + HYB together = ~2× storage for same satellite imagery. Users who want both should understand the duplication. At least one layer must remain checked.

12 Key SQL Queries
Assets in Viewport
-- Tracks in viewport SELECT track_id, name, difficulty, distance_mi, file_path, trailhead_lat, trailhead_lon FROM tracks WHERE bounds_w < :east AND bounds_e > :west AND bounds_s < :north AND bounds_n > :south ORDER BY created_at DESC LIMIT 20; -- Routes in viewport SELECT route_id, name, type, difficulty, distance_mi, file_path, trailhead_lat, trailhead_lon FROM routes WHERE bounds_w < :east AND bounds_e > :west AND bounds_s < :north AND bounds_n > :south ORDER BY created_at DESC LIMIT 20; -- Trailheads in viewport SELECT waypoint_id, name, lat, lon, parking_available, facilities FROM waypoints WHERE icon_type = 'TRAILHEAD' AND lat BETWEEN :south AND :north AND lon BETWEEN :west AND :east;
Unified Asset Search
SELECT 'track' AS type, track_id AS id, name, distance_mi, difficulty, bounds_n, bounds_s, bounds_e, bounds_w, trailhead_lat AS lat, trailhead_lon AS lon FROM tracks WHERE name LIKE :query UNION SELECT 'route', route_id, name, distance_mi, difficulty, bounds_n, bounds_s, bounds_e, bounds_w, trailhead_lat, trailhead_lon FROM routes WHERE name LIKE :query UNION SELECT 'trailhead', waypoint_id, name, 0, NULL, lat, lat, lon, lon, lat, lon FROM waypoints WHERE icon_type = 'TRAILHEAD' AND name LIKE :query UNION SELECT 'waypoint', waypoint_id, name, 0, NULL, lat, lat, lon, lon, lat, lon FROM waypoints WHERE icon_type != 'TRAILHEAD' AND name LIKE :query ORDER BY name;
Rides Departing from Trailhead
-- 0.004 degrees ≈ 0.25 miles proximity threshold SELECT r.ride_id, r.name, r.ride_date, r.is_public, u.first_name, u.last_name FROM rides r JOIN users u ON r.organizer_id = u.user_id WHERE r.trailhead_lat BETWEEN :lat - 0.004 AND :lat + 0.004 AND r.trailhead_lon BETWEEN :lon - 0.004 AND :lon + 0.004 AND r.ride_date >= CURDATE() ORDER BY r.ride_date ASC;
