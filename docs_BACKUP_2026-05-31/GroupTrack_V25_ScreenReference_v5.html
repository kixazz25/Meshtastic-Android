10. DATA MODEL + DATABASE REFERENCE

SPATIAL DATABASE: grouptrack_spatial.db (WKT geometry, portable to iOS)
✓ CREATED — Documents/GroupTrack/grouptrack_spatial.db
trails: trail_id, name, geometry(LINESTRING WKT), timestamps
tracks: track_id, name, bbox(POLYGON WKT), timestamps
waypoints: waypoint_id, name, type, geometry(POINT WKT), timestamps
routes: route_id, name, geometry(LINESTRING WKT), timestamps

EXTENSION DATABASE: grouptrack_data.db
✓ CREATED — Documents/GroupTrack/grouptrack_data.db
trail_properties: 20+ fields (UGRC superset), source_id, shared
track_properties: filename, distance, duration, speed, shared
track_surveys: enjoyment 1-5, ride_again Y/N
waypoint_properties: description, elevation, shared
route_properties: distance, method, source_track_id, trailhead_id, shared
artifact_aliases: unified, all types, is_preferred LOCAL ONLY
proximity_config: soft-coded thresholds (seeded with defaults)
tile_queue, upload_queue, download_queue: three separate tables
transfer_history, data_log, trail_sources, source_ingestions, ride_areas

WKT HELPERS (SpatialDbManager):
✓ pointWkt(lat, lng) / lineWkt(points) / bboxWkt(n,s,e,w)
✓ parsePoint(wkt) / parseLine(wkt) / parseBbox(wkt)
✓ newId() = UUID / now() = ISO 8601

Tracked per database. Migration support built in.
