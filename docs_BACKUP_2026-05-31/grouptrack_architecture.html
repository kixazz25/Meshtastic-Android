RIDES RULES
CREATE RIDE only accessible if is_organizer = TRUE and organizer_terms_accepted_at is set.
Private rides: invite link only. No broadcast. No discovery. No email.
Public rides: broadcast to followers via email. Discoverable in Explore. No personal invite link.
broadcast_sent flag is permanent once set. API returns 409 if broadcast attempted twice. Button disabled.
Invite acceptance triggers: ride download + map tile download + enrollment POST. All automatic.
Map tiles download uses bounds from rides.map_bounds_* set by organizer at ride creation.

TRACKS RULES
Difficulty score numeric: Easy = 1.0, Moderate = 2.0, Hard = 3.0. Average computed from all survey responses for rides that used this track.
Would ride again % = COUNT(recommend=Yes) / COUNT(*) from ride_surveys for rides using this track.
Downloading a track automatically queues map tile download for the track bounding box. Same mechanism as invite acceptance.
Track detail is an inline expand panel — not a separate screen. Tap to expand, shows mini map with GPX line, distance, elevation, stats, would ride again %, download button.
USE AS ROUTE sets rides.route_id when organizer creates next ride. Track selected from library, not imported again.
SOLO mode riders can download tracks as reference overlays on the map. No radio or ride needed.

STOP RECORD
Two dialog paths controlled by RideState — simple (SOLO/CONVOY) or survey+save (ORGANIZED)
2 dialog variants · Survey queued locally · Uploads on next connectivity
2 DIALOGS
▼
DIALOG ASOLO / CONVOY
Simple Track Save
No survey. Track name required — SAVE disabled until filled. Track saved to device tracks directory. No database impact. No donation.
Track name Saved to filesDir/my_tracks/ GPX format (default)
→ Map (IDLE)
DIALOG BORGANIZED
Survey + Track Save
Three checkboxes above track name. Fast — 15 seconds in field. Survey queued locally, uploads when connectivity returns. Track donated if share checked.
Difficulty: Easy/Moderate/Hard Would ride again: Yes/No Share track with community: Yes/No Track name (pre-filled from ride name) SKIP SURVEY saves track only ride_surveys queued locally ride_tracks uploaded if shared
→ Map (IDLE)
STOP RECORD RULES
RideState determines which dialog appears. SOLO or CONVOY → Dialog A. ORGANIZED → Dialog B.
Track name pre-populated from active ride name in ORGANIZED state. Rider can edit.
SAVE disabled until track name is not empty in both dialogs.
Survey queued to SharedPreferences immediately. Uploaded via PATCH /ride/survey on next connectivity — radio offline is irrelevant.
Track donation: MD5 computed on device, POST /ride/survey with track_donation payload. Silent discard if hash exists.
Post-ride notes entered later from Ride History expand panel — not at STOP time. No notes field in the field dialog.
